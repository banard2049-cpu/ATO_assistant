# ATO Assistant 4.0.0

## 更新

本次重点是 C4、C5 八位反面大卡（AIBP）的卡面汉化。

- 新增这八位反面大卡的中文卡面，共 317 张。放大卡图后可在右上角切换中文与英文原图，卡牌缩略图使用同一开关；译文按卡面原有的分行位置排布，标题、正文与数值各就其位，不改变原图版式；BOSS 名称随语言设置显示官方或民间译名，标题与正文一并替换。
- 新增五个循环共 223 张探索卡的中文译文：桌面端悬停显示，移动端点按打开面板，外交关系分支与资源、指示物均以图标标注。
- 调整登升的保存方式，装备与升华核心改为一次提交，重试或刷新不会重复扣除核心。
- 调整地图撤销，改为只回退本次操作，不再覆盖其他页面已同步的移动与笔记。
- 加强一键更新的版本校验：更新前向 GitHub 核对发布标签与文件差异，下载内容逐个校验，不一致时停止安装。
- 修正第二屏战斗视图在浅色主题下底色偏白、文字对比不足的问题。

继续使用现有存档和游戏资源，无需更换资源包；已有库存、核心余额与地图进度不受影响。从 3.11.x 升级可使用应用内一键更新，也可下载完整安装包覆盖。
