## 更新

**本次更新仅影响 Android。Windows、macOS 和 Docker 用户无需更新。**

Android 版的 `.atopack` 资源导入名单已同步到最新素材清单，新增 C1 隐藏探索卡 `8201`。旧版 Android 应用会因为内置名单缺少该条目而拒绝导入对应资源；更新到 1.3.3 后即可正常校验和安装。

本次没有改变游戏流程、存档格式或其他平台功能。

## 下载

Android 用户请下载下方的 `ATO-Assistant-1.3.3.apk`。Windows、macOS 和 Docker 用户继续使用 1.3.2 即可。

Android 沿用现有签名策略：未配置发布签名密钥时提供 Debug 签名 APK。不同构建的签名可能不一致，若系统提示无法覆盖安装，请先确认应用内账号、存档和素材均可恢复；卸载应用会删除这些本地数据。

游戏图片、完整故事正文和 `.atopack` 资源包仍由用户本地提供，不包含在 APK 中。

## 验证

- Android 导入名单专项测试通过：共 4291 个资源映射，包含 C1 探索卡 `8201`。
- 素材库固定清单升级测试覆盖旧清单自动补入 `8201`，并确认已有素材不会被清除。
- `.atopack` 合法路径、导出和安装安全回归测试覆盖更新后的 2769 个清单条目与 4291 个目标。
- Android APK 及发布附件由 GitHub Actions 构建，结果以本页附件和 Actions 记录为准；未进行 Android 实机安装验证。
