## 更新

本版本加入**探索卡资源自动结算**，并把官方版故事书扫描图、素材库资料包和固定清单的一批问题一并修掉。

### 探索卡资源自动结算

抽出探索卡后，卡面上「只加资源」的卡会多出一块结算区块，点一下按钮就按当前外交状态把卡面写的资源直接写进记录表：

- **纯资源卡**显示「自动结算」；**含其它效果**的卡显示「结算资源部分」，并把其余效果逐条列成待办（`You may …`、二选一、掷骰这类需要玩家决定的句子一定留给人处理）。
- 资源卡上的条件就是卡面那枚外交状态徽章（`Allied`、`Friendly+`、`Denounced-`、`At War` 等），判定用的是主控台工具栏已经在显示的同一份数据——阿尔戈号当前所在板块的阵营外交状态。
- 条件无法自动判定时给出分支按钮（`基础值结算` 与各条件分支），按钮标题写明生效条件与将写入的内容，由玩家按实际战况选择；当前外交状态下没有资源收益的卡不会给一个点了没反应的按钮。
- 写入走记录表服务端存档，带冲突重试和同步日志；结算后可随时「撤销结算」，撤销同样是一条可追溯的日志。结算状态按循环 / 天数 / 卡号记录，重新抽卡即开始新一轮结算。

卡面规则文字只印在图片上，程序手里原本没有「这张卡给什么资源」的数据，因此本版本把这批数据做了出来并随仓库提供：

- `assets/exploration-card-resources.js`：222 张探索卡（c1–c5）的结构化资源数据（脚本生成，勿手改）；
- `assets/exploration-card-resource-rules.js`：条件求值、结算计划、写记录表与撤销的运行时逻辑；
- 判定规则、数据来源与重新生成方式见 `tools/exploration-card-resources.md`；逐张卡的判定复核表在 `tools/exploration-card-resources-review.csv`；
- 数据由卡面视觉转录（`tools/exploration-card-effects.json`）经 `tools/merge_exploration_vision.py` 合并、`tools/scan_exploration_resource_cards.py` 扫描生成；`tools/ocr_exploration_cards.py` 的默认循环也从 c1–c3 扩展到 c1–c5。

### 探索卡与仪表盘

- 抽出的牌只显示牌面本身：天数、卡名、黑底编号和移出 / 连抽标签不再重复印在卡下方（卡面上本来就有），抽出张数由上方状态行统一说明。
- 「放回暂时移出」按钮只负责放回，不再悬停弹出卡牌预览——鼠标扫过就弹窗反而挡住牌面，暂时移出的牌在下方折叠区里本来就能看到。
- 「已选 N / M 张」跟着「选择探索卡库」入口走，不再占用抽牌那一行。
- 宿敌控制（生成宿敌 / 追击 1 格）固定在探索步骤的 Map 按钮后面，与第二屏幕开关无关。
- 第七步（灾祸 / 末日）在特殊事件后面新增「进入下一天」，点完自动回到页首；日期轨只滚动自己的列表，不再把整个页面拽走。
- 步骤标题行里的入口按钮与探索卡工具区按钮统一尺寸；灾厄卡与故事卡弹窗宽度对齐，灾厄卡面不再比故事卡小。

### 官方版故事书与扫描图

- 官方版数据声明了扫描图，不代表本机真有这张原书页（民间版资源包不带扫描图）。现在加载失败过的条目会被登记：扫描图那一块整体换成统一提示，不再留一个加载失败的方框，之后也不再重复发必然失败的图片请求。
- 同一批条目上的「第二屏显示原书扫描图」勾选框会按「没有扫描图」处理（弹回并禁用，提示改为「本机没有这张原书扫描图，第二屏会改为显示官方正文」），第二屏快照直接发官方正文。

### 素材库与资源包

- **官方版故事书截图默认不打包**：对外发布的民间版 `.atopack` 只带官方故事书正文数据；需要官方版资料包时，在导出面板勾选「包含官方版故事书截图」，或给 `build_full_pack.py` / `update_full_pack.py` 加 `--include-official-scans`。重建旧包时默认把旧包里的截图丢掉，加参数才保留。
- 官方截图后缀放宽为 `.jpg / .jpeg / .png / .webp`，并且**不限大小写**（`.JPG`、`C1-0-0.PNG` 同样收）。打包、校验、素材库导入、安装回原项目、Android 端导入与第二屏快照用的是同一套规则；`.gif` 之类仍然拒绝。
- 官中图片覆盖（`official-assets/`）允许扩展名与清单不一致：`CARD.png` 能匹配清单目标 `CARD.jpg`（反之亦然），大小写也不影响；匹配仍要求「去掉后缀后唯一」，同名候选多于一个时照旧回退到素材库 / 项目原图。写进资料包的路径始终照清单目标，不会因为放了别的后缀而改变包内结构。
- 固定清单补登通用 Trait **「逆行动量 / Reverse Momentum」（CT1326）**：应用里它只在 C3 Boss 的 Trait 列表可选，图片位置固定为 `aibp/ps/other/trait/COMMON_TR_002.jpg`，但清单此前漏登记——素材库不提示拍摄、打包也带不上它。清单规模 2774 → **2775** 条、4296 → **4297** 个目标。

### 打包与发布

- 公开审计允许清单加入探索卡资源文件，`.gitignore` 同步放行 `assets/exploration-card-resources.js` 与 `assets/exploration-card-resource-rules.js`：这两个文件被 `index.html` 直接引用，若漏进版本库，CI 全新检出构建出来的安装包会缺文件。
- Android 端官方资料路径规则与桌面端对齐：后缀不限、大小写不敏感，扫描图的 MIME 类型按实际后缀给出（此前固定为 `image/jpeg`）。

## 下载

Windows、macOS、Android 请下载下方对应安装包。便携版请解压到新目录，并保留旧版本的 `data/` 和本地素材目录。

Docker 的 `latest` 标签同步更新至 1.4.0。如果此前在 `.env` 中固定了版本，请改为 `ATO_VERSION=1.4.0`，然后运行：

```bash
docker compose pull
docker compose up -d
```

Android 沿用现有签名策略：未配置发布签名密钥时提供 Debug 签名 APK。不同构建的签名可能不一致，无法保证覆盖升级；卸载会删除应用内账号、存档和素材，升级前请确认数据可恢复。

另外，Android 端内置的资源名单是打包时生成的：**1.4.0 之前构建的 APK 不认「逆行动量」这条新资源**，导入包含它的 `.atopack` 会被拒绝，需要更新到 1.4.0。

游戏图片、完整故事正文、官中覆盖图片和 `.atopack` 资源包仍由本地资料提供，不包含在公开安装包中。「逆行动量」的卡图同样需要自备，位置为 `aibp/ps/other/trait/COMMON_TR_002.jpg`。
