## 旧版 Docker Compose 兼容预发布

- 新增 `compose.legacy.yaml`，支持 docker-compose v1（1.21.0+），适用于使用旧版 Compose 的 32 位 Raspberry Pi OS（ARMv7）。
- 保留全部 15 处存档和素材挂载，移除旧版不支持的 Compose 配置项。
- Docker ZIP 安装包附带兼容配置与启动说明。

## 使用方式

下载并解压 Docker ZIP，在安装目录执行（已有底图必须是文件，不能是目录）：

```bash
mkdir -p data app/ss
touch app/ss/battle-board.jpg
ATO_VERSION=1.3.7-rc.1 docker-compose -f compose.legacy.yaml pull && ATO_VERSION=1.3.7-rc.1 docker-compose -f compose.legacy.yaml up -d
```

访问 `http://服务器IP:8793/`。也可在同目录 `.env` 中设置 `ATO_VERSION=1.3.7-rc.1`，后续更新始终先 pull 再 up。

预发布镜像标签为 `1.3.7-rc.1`，不更新稳定版 `latest`。镜像提供 `linux/amd64` 和 `linux/arm/v7`；32 位 x86 不在支持范围内。

本地完成挂载检查、许可证测试和公开发布审计；未在 32 位实机运行验证。

Android 沿用现有签名策略：未配置发布签名密钥时提供 Debug 签名 APK，不保证覆盖升级，请先备份数据。
