# ATO Assistant 3.7.4

## 更新

- 修正主控制台音乐音量滑块左右两端留白、滑块看起来无法到头的问题；移除误继承的文本输入框内边距和边框。
- 修正须目刻托斯之战的 1×5 光墙朝向与翻面，以及福波斯之龙的光墙翻面、负重者两种布置中的 6 片 O 形悬崖朝向。
- 修复 TTS 地形导入脚本漏读旋转参数的问题，自动更新未编辑的旧地形预设。
- 从公开仓库移除内部使用的 TTS 桌游调研向导文档。

继续使用现有存档和游戏资源，无需更换资源包。本次版本不包含正在开发的 TTS 桌面功能及锚点素材改动。

## 下载

- Android：`ATO-Assistant-3.7.4.apk`。
- Windows：`ATO-Assistant-Portable-3.7.4-windows-x64.zip`。
- macOS：`ATO-Assistant-Portable-3.7.4-macos-arm64.zip`、`ATO-Assistant-Portable-3.7.4-macos-x64.zip`。
- Docker：`ghcr.io/banard2049-cpu/ato_assistant:3.7.4`，同时更新 `latest` 标签。

下载附件由 GitHub Actions 构建后上传。
