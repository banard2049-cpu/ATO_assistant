# ATO Assistant 3.7.5

- 新增战役日志：自动记录资源、矩阵、冒险、外交、科技、装备、英雄、AIBP 和故事阅读变化，并保留已有手写笔记。
- 战役日志打开及收到新记录时自动显示最新内容；每条记录带来源、循环与已有的战役天数。
- 精简 AIBP 日志，每次保存有变化时只追加一条简短摘要；切换敌人只记录战斗对象，抽牌省略重复牌堆数量。
- 修正秘密装备牌的导出，提供可用于游戏的牌面。
- 简化英雄可能性图标，改善窄屏标题显示。
- 包含此前预发布版的官方中文外交译名修正，覆盖记录表、探索派系状态与探索卡结算显示。

程序更新不包含个人存档及游戏图片、故事、音频等资料；已有资料与战役存档继续保留。
