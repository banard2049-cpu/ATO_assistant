# ATO Assistant 2.0.4 发布报告

本版包含 2.0.4-rc.1 的战斗操作、故事卡窗口和素材包工具更新，并修正主控制台的宿敌生成与追击。可直接从 2.0.3 或更早版本升级。

> **尚未安装 2.0.3 的玩家请更新到本版。** 2.0.3 订正了阿尔戈号记录表的冒险轨框数，本版完整包含该订正。升级后请核对当前冒险进度；此前因缺格未能记录的进度需要手动补记。已有勾选不会重新排列。

## 更新

## 宿敌生成与追击

- 主控制台与地图模块现在共用同一套地图布局、已揭示板块、翻面连接、相邻判定和最短路线规则。多条路线等长时，追击会按地图模块的方向优先级走，不再从主控制台走向另一格。
- 生成宿敌也共用地图模块的候选计算：只允许放在距离阿尔戈号正好 4 格的已揭示板块。存在多个合格位置时，主控制台会列出位置供玩家选择，不再随机放置。
- 如果没有已揭示路线，宿敌留在原位，主控制台会提示未移动。

## 包含 2.0.4-rc.1 的更新

- AI、BP 撤销分别保留最近 30 步，可跨另一类操作连续回退，刷新后仍可使用；联动结算分别回退，达哈卡共用牌堆仍按共用规则处理。
- BPⅠ、Ⅱ的暴击按钮按普通击败结算；BPⅢ保留原有暴击结算。地形改为双击选中或取消，视线判断模式仍可单击设置位置。
- 故事卡与知识面板调整布局，窄屏可滚动查看。
- 民间版和官方版素材打包命令支持 `--incremental-from` 复用上一个资料包中的未变成员，并保留产物校验；为两张官中大幅特性卡补充图片压缩豁免。

## 记录表框数订正提醒

如果跳过了 2.0.3，本版也包含以下订正：循环 I 的「宿命的谜题」「人民的困境」「隐匿于众目睽睽之下」「目标明确的人」「暴露的梦境」，以及循环 III 的「鲜为人知的路」「太阳之子」「我们身后留下的」「步入成熟」，均由 4 格改为 5 格；循环 IV 的「三重诅咒之地」由 5 格改为 4 格。循环 I「教程」的中间空白格限制也已修正。详情见 [2.0.3 发布说明](https://github.com/banard2049-cpu/ATO_assistant/releases/tag/v2.0.3)。

**官方故事书另有勘误更新。** 安装助手新版本不会替换本地故事书；使用官方故事书的玩家，请从原获取渠道下载最新版，并更新相应故事数据或资料包。

- 2.0.4-rc.1 的战斗、故事卡和素材包验证记录见 [预发布报告](https://github.com/banard2049-cpu/ATO_assistant/releases/tag/v2.0.4-rc.1)。
- Windows、macOS、Android 安装包由发布工作流构建，实际产物以本页附件和工作流结果为准；未进行这些平台的实机安装验证。

## 下载与升级

Windows、macOS 和 Android 请下载本页对应安装包。便携版建议解压到新目录，保留旧版 `data/` 和本地素材。Docker 正式版镜像构建完成后，`latest` 指向 2.0.4；如在 `.env` 固定了旧版本，请改为 `ATO_VERSION=2.0.4`，然后运行：

```bash
docker compose pull
docker compose up -d
```

Android 沿用现有签名策略；如未配置正式发布签名，工作流会生成 Debug 签名 APK。不同签名的安装包可能无法覆盖升级；需要卸载时，请先确认应用内账号、存档和素材可以恢复。

公开安装包不包含本地游戏素材、故事书、音乐、资料包或用户存档。
