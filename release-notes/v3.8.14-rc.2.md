安卓导入完整资源包的内存修复预发布。

- 安卓导入 `.atopack` 时不再把十几 MB 的 `story/entity-index.json` 整份读入并解析成 JSON 对象，也不再重复序列化出 JSON 和 JS 两份文本；人物小传索引改为校验大小与 SHA-256 后流式落盘，由故事页自行解析。
- 故事正文改为逐段写入，避免先拼出完整 JS 字符串再转成 `byte[]`。
- APK 启用大堆，并捕获导入线程的内存异常：内存不足时回到页面提示，不再直接结束应用。
- 其余功能与 3.8.14-rc.1 相同，继续支持旧 PNG 蒙版和新 SVG 蒙版资源包。

请先安装本次 APK，再重新导入资源包。若旧版导入曾在选包后闪退，可先清除 ATO 缓存（不要清除应用数据）并重启手机再试。
游戏素材包由使用者另行准备，本次程序预发布不附带游戏素材。

验证：旧版在 128 MB 堆下导入 13 MB 清单和 17 MB 人物小传时复现 `OutOfMemoryError`；新版在 96 MB 堆下通过。414 项安卓导入器行为检查通过。
