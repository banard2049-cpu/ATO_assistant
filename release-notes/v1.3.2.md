## 下载

Windows、macOS、Android 请下载下方对应安装包。便携版请解压到新目录，并保留旧版本的 `data/` 和本地素材目录。

Docker 的 `latest` 标签同步更新至正式版 1.3.2。如果此前在 `.env` 中固定了预发布版本，请将其改为 `ATO_VERSION=1.3.2`，然后运行：

```bash
docker compose pull
docker compose up -d
```

Android 沿用现有签名策略：未配置发布签名密钥时提供 Debug 签名 APK。正式版本号不改变签名方式，不同构建的签名可能不一致，无法保证覆盖升级；卸载会删除应用内账号、存档和素材，升级前请确认数据可恢复。

游戏图片、完整故事正文和 `.atopack` 资源包仍由本地资料提供，不包含在公开安装包中。
