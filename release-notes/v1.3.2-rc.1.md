## 更新

> **这是预发布版本（rc）**，用于验证 1.3.1 之后的一轮代码审计修复。功能与 1.3.1 一致，主要改动集中在安全性与健壮性。遇到问题请回报，正式版会在此基础上发布。

本轮修复来自一次完整的代码审计复核，涉及私有数据暴露、局域网多账号串档案、资料包导入安全、打包与发布链路。

### 私有文件不再可下载（安全）

- 之前把仓库根目录当作站点根、且 `data/` 也在其中，于是**局域网里任何人都能直接下载** `data/ato-users.json`（账号口令哈希）、`data/ato-campaign-*.json`（完整存档）、`data/sessions`、`data/backups` 与旁边的 `*.lock`。现在启动脚本一律把 `router.php` 作为路由脚本交给 PHP 内置服务器，`data/`、`tmp/`、`export/`、日志目录与 `.htaccess` 本身一律 403。
- 修复了一条绕过：以「绝对形式请求目标」（`GET http://主机/data/... HTTP/1.1`，`curl -x` 就是这么发的）请求时，此前的判断读的是原始请求行，会把 `http:` 当成路径首段从而放行。现在以服务器实际解析出的路径为准，并保留一份兜底候选，只可能「多挡」不可能「漏挡」。
- `tools/xfyun-long-tts.config.json`（本地语音合成密钥）也在拦截名单里 —— 它此前同样可被局域网下载。**建议轮换一次该密钥。**
- Apache / NAS 部署（两份 `docker-compose*.yml`）同样收口：`.htaccess` 现在真正生效（此前 Debian 默认 `AllowOverride None` 会让它被整个忽略），并且容器只挂载应用需要的目录，不再把整棵仓库目录放到 11451 端口上。

### 局域网多账号不再串档案

- 主控台此前不校验「这次读取属于哪个账号」：另一个标签以别人的身份登录后，本页会把**别人的存档**合并进来显示，随后的保存被服务端拒绝，于是陷入「保存失败，等待重试」的无限循环、却从不提示刷新。现在主控台、地图、记录表、科技、英雄、第二屏、导出与地图命令全部校验账号身份，发现不一致就立即停止保存并提示刷新页面。
- 地图命令在 409 重算时不再串档案：以前「切换档案 + 请求在途」会把旧档案的编辑静默写进新档案。
- 服务端把 `expectedAccountId` 的空字符串视为「未声明」（此前会被当成「另一个账号」直接 409，页面只能靠刷新恢复）。
- `data/ato-users.json` 加了文件锁：两个容器进程同时注册时，此前会出现「接口返回成功、账号却没落盘」，用户此后永远登不进去。
- Android 端的 `write()` 补上了与 PHP 侧同样的账号校验。

### 在线语音合成（讯飞）在局域网地址下可用

- 之前浏览器端签名只走 `crypto.subtle`，而它**只在安全上下文**（https / localhost）存在；应用按设计跑在 `http://<局域网IP>:8793/`，所以在线合成在局域网地址上必然失败、并报「当前环境不支持 Web Crypto」。现在自带一份纯 JS 的 HMAC-SHA256 兜底（有 `crypto.subtle` 时仍用原生实现），在 http 地址下也能正常签名。

### 便携版：解压目录名带空格 / 括号也能启动

- 解压到 `ATO-Assistant-Portable-1.3.1-windows-x64 (1)` 这类目录（含空格、`&()![]`、中文）时，`session.save_path` 会被 PHP 的 INI 解析截断，导致 `session_start()` 失败、登录态全丢。现在改由 PHP 自己生成一份 INI 并用 `-c` 启动，路径不进任何命令行。macOS 与 Windows 两侧、便携版与仓库根启动脚本都已修正。

### 超大存档请求返回明确错误

- 此前超过 PHP `post_max_size` 的请求会返回 **200 + 一段 HTML 警告**（前面还可能挂着 `AUTH_REQUIRED`），客户端无法解析。现在启动器生成的 INI 把 `post_max_size` 抬到接口自身上限之上，超大请求统一返回 `413 {"code":"PAYLOAD_TOO_LARGE"}`；同时关闭 `display_errors`、保留 `log_errors`（错误仍出现在启动器自己的控制台窗口里，便于排查）。

### asset-studio：资料包导入与安装安全

- 恶意或损坏的 `.atopack` 以前可以让**任意文件写到项目之外**（清单里 `faces` 值含反斜杠时，渲染文件名会被当成单个相对分量从而跳出临时目录），也能把 `.js`/`.php` 之类文件静默装进项目。现在导入与安装都走同一套严格路径校验：拒绝反斜杠、盘符、UNC、`..`、Windows 设备名、结尾点/空格与非法字符，并且**安装目标只允许图片**（`.jpg/.jpeg/.png/.webp`，限素材目录）**与 `assets/bgm/` 下的音频**（`.mp3/.ogg`）；内置清单的 4290 个目标全部照旧通过。
- 导入时校验清单声明的 sha256（此前导入不校验，字节与声明不符会静默指向库中另一张图）；失败导入不再留下 `library/tmp` 副本、不再半途写清单（会回滚）；资料包增加成员数量与体积上限。
- 安装失败不再把临时文件留在项目里；别名目标（`x.png` / `X.png` / `x.png.`）不再破坏回滚备份（此前会让回滚把用户原图换成中间态）；目标位置是同名文件夹时给出明确错误而不是 500。
- 配对码限流改为按客户端计数（此前一个局域网客户端连发 5 个错码就能把所有正常手机锁住）；Host/Origin 校验不再误伤端口映射与反向代理；分块上传改为边读边限制（此前先把整个请求体读进内存）。

### 发布与测试链路

- 打包排除规则补齐：新增的 `tests/` 与 `docker-compose.nas.yml` 不再进便携版 / Docker / APK；并新增断言，确保 `router.php`、`assets/campaign-session.js` 这类**启动必需**的文件绝不会被排除掉。
- 若干此前静默失效或挂死的测试修好并纳入回归：地图存档冲突、AIBP 轮回特性、便携启动器（后者此前会无限挂起并残留进程）。
- 新增回归测试：局域网账号守卫、前一天恢复、资料包恶意路径与安装目标安全、讯飞签名（含无 `crypto.subtle` 的兜底路径，用 Node 的 HMAC 逐字节比对）。

### 需要注意的变化

- **第二屏地址现在带 token**：`/ss/?token=…`。此前无 token 的地址会返回 403，请从主控台「用户与存档」里重新复制地址（同一个浏览器仍可直接打开，页面会把 token 记成 cookie）。旧书签需要更新。
- **Docker / NAS 不再挂载 `tools/`**（避免本机草稿与密钥进入容器）。地图页的「标签编辑器」链接在容器部署里会 404；该工具本就属于本机素材整理，便携版与发布包同样不含 `tools/`。
- 写存档时如果目标文件正被别的程序占用，现在会返回可重试的 500，而不是退回「就地覆盖」把正在被读取的存档截断重写。

## 下载

Windows、macOS 和 Android 请下载下方对应安装包。Docker 镜像同步更新：

~~~bash
docker compose pull
docker compose up -d
~~~

便携版从旧版本升级时，请解压到新目录并保留旧的 data/ 目录，登录账号和存档都在其中。**升级后请确认 `data/` 不在任何静态目录里对外暴露。**

**本次预发布没有 APK**：仓库未配置 Android 发布签名密钥，发布流程会跳过 Android 构建（不再生成 Debug 签名的安装包 —— 那种包之后无法被正式签名的版本替换，装了只能卸载重装）。Android 用户请继续使用 1.3.1，或等正式版 1.3.2；届时若配置了签名密钥，APK 会自动回到发布附件里。

游戏图片、完整故事正文及 atopack 资源包由本地资料提供，不包含在公开发布附件中。
