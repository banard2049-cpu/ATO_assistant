# ATO Assistant 3.5.10-rc.1

本次预发布集中改进计数标记，并修复 Android 简报、英雄存档导出和存档落盘问题。

## 更新

### 计数标记与旧存档

- 「计数标记」改为名称和数量组成的紧凑列表。点击标题右侧「＋」新增，可直接修改名称、数字，使用加减按钮调整数量，或删除条目；数量最低为 0，各循环独立保存。
- 新增框默认收起，计数按钮沿用记录表配色；加号与减号使用固定图形定位，避免字体基线导致图标偏离按钮中心。
- 旧存档中的计数文字自动移到对应循环「战役笔记」开头，以「【原计数标记】」标明来源，保留既有笔记；读取旧档后自动同步迁移结果，重复加载不会重复迁移。
- 修复 PHP 将空循环对象编码为数组后，新记录在保存时消失的问题；写入前恢复为对象，确保计数与笔记可以正常保存。

### Android 导出与保存

- 战役简报 ZIP 通过系统文件保存入口导出，包含地图 GIF、科技 GIF 和逐日 PDF。页面等待系统确认写入成功后才显示导出完成，取消和失败会给出提示并允许重试。
- 修复 Android WebView 的本地图片污染 Canvas、导致 GIF/PDF 无法导出的问题：导出时从资源包或 APK 内读取图片为独立数据，科技树 SVG 也使用独立数据地址栅格化。
- 英雄存档 JSON 同样使用系统保存入口；桌面浏览器保留原有下载方式。
- 本机存档、账号切换、退出登录及备份采用同步提交，写入失败会返回错误，避免已显示保存成功的数据在应用进程结束后丢失。

### 开发调试

- 增加项目专用 Android 模拟器的准备、构建、启动、安装、日志和状态工具，以及调试说明。
- 新增真实 WebView 回归入口，覆盖模块导入、逐日备份、恢复前一天、附件、账号隔离、第二屏与进程重启后的持久化；默认仅操作项目指定模拟器。

- 前端及故事回归 721 项通过；仅排除本机私有素材的逐条双页面长时间穷举检查。
- 计数列表已在浏览器验证新增、加减、手机宽度显示和按钮居中；覆盖旧文字迁移、幂等加载、空数组存档兼容、循环隔离和并发合并的回归测试已通过。
- Android Java 回归通过：战役导入 102 项、简报 45 项、文件导出 10 项、持久化 60 项、资源包导入 117 项；附件存储与账号隔离检查通过。
- Android 资源目录检查通过：4826 项映射，222 个普通探索入口与 1 个隐藏探索入口；目录覆盖与公开打包许可测试通过。
- 本地 Android APK 构建成功；Android 15 模拟器真实 API 102 项通过，应用强制重启后存档与附件保留，8 个模块页面全部正常加载。
