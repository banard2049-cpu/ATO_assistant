# ATO Assistant 3.8.6

修正资源兑换类别上限，增强装备制造重试与记录表导入保护，并包含 3.8.6-rc.1 的科技名称和资源图标更新。

> **请同步更新 ATOPACK。** 本版沿用预发布版更新的资源和派系图标。尚未导入新版资料包的用户，请在更新程序后重新导入最新版 ATOPACK；仅更新程序不会替换本地游戏素材。

## 更新

- 商人交易每轮最多选择 5 类兑换，同一种兑换可填写多次倍率且只占 1 类额度；已使用的类别可继续加量。旧兑换记录按回执恢复类别统计，支持撤销。
- 常驻科技贸易和城镇谈判贸易按资源置换类别计算上限，同类倍率不额外占用额度；重复类别合并到一行填写，保留原有成本校验、冷却和结算顺序。
- 装备制造保存操作回执；保存响应丢失时可点击“确认上次制造结果”重试，避免同一次操作重复扣料或增加装备，并检查当前档案与登录账号。
- 记录表导入先验证备份结构，拒绝完整战役备份及其他模块导出，避免错误文件被转换为空记录表。完整战役备份请从主控台导入。
- 科技树外的科技引用统一使用深色面名称，涵盖交易来源、能力面板、时间线、提醒、已解锁卡牌列表和简报；科技树仍显示正面名称。
- 更新记录表资源与派系图标，AIBP 战利品面板复用记录表图标；素材库清理已停用的独立 AIBP 资源图和无用标记，并调整部分控件与记录表分隔线外观。
- 移除资源交换中的“当前正在发展阶段”复选框及对应校验，保留“故事 2A 或之后”的条件确认。

## 下载与升级

在本 Release 的 Assets 中选择 Android APK 或 Windows／macOS 便携包。Docker 使用 `ghcr.io/banard2049-cpu/ato_assistant:3.8.6`，正式版同时更新 `latest`。

程序包不包含个人存档及游戏图片、故事或音频资源；已有战役存档继续兼容。资源兑换修正作用于后续操作，不追溯修改历史资源数量。

## 验证

548 项 JavaScript 回归测试通过，覆盖探索结算、科技与谈判规则、制造重试、记录表导入及相关显示。发布资源审计、发布附件规则和打包排除检查通过。Android、便携包和 Docker 镜像由本标签对应的 GitHub Actions 构建发布。
