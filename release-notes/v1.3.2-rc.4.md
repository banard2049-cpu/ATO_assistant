## 下载

Windows、macOS、Android 请下载下方对应安装包。便携版请解压到新目录，并保留旧版本的 `data/` 和本地素材目录。

Docker 用户使用此预发布版时，在安装目录的 `.env` 中设置 `ATO_VERSION=1.3.2-rc.4`，然后运行：

```bash
docker compose pull
docker compose up -d
```

预发布版不会更新 Docker 的 `latest` 标签。

Android 沿用现有签名策略：未配置发布签名密钥时提供 Debug 签名 APK。不同构建的签名可能不一致，无法保证覆盖升级；卸载会删除应用内账号、存档和素材，升级前请确认数据可恢复。

游戏图片、完整故事正文和 `.atopack` 资源包仍由本地资料提供，不包含在公开安装包中。
