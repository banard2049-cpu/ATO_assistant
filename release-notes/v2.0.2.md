## 更新

本版是 **2.0.2**，相对 `2.0.1` 是两件事：**Docker 部署终于能显示循环图标**，以及
**记录表里 C1「教程」冒险的格子数改回 3 个**。

### 容器部署：循环图标素材补上挂载点

五个循环的标记图标（`assets/cycle-symbols/*.png`）是版权素材：不在 git 里，也就不在公开镜像里
（CI 从 git 检出构建）。而 `compose.yaml` 与 `compose.legacy.yaml` **都没有挂载这个目录**，
于是用 `tools/install-docker.sh` 装的部署里，主控台、地图、记录表、英雄、剧情五个页面的循环标题前
**永远没有图标**，而用户连自备素材都没有地方放 —— 源码部署（仓库根的 `docker-compose.yml` 挂整棵
`assets/`）反而是好的，所以本地测试完全看不出问题。

现在：

- `compose.yaml` / `compose.legacy.yaml`：挂载 `./app/assets/cycle-symbols`，与
  `exploration-cards` 等同类素材一致（可写，它是 asset-studio 的导入目标）；
- `tools/install-docker.sh`：建出对应目录；
- `tools/test_docker_mounts.py`：`REQUIRED_TARGETS` 收进该目录，并新增断言 —— **两份 compose
  的挂载目标必须完全一致**（循环图标正是「两份都漏」才一直没人出声）；
- `tools/packaging/docker/README.txt`：列出该目录与需要保持的 5 个文件名。

缺图只会表现为「没有图标」：`cycle-symbols.js` 会移除加载失败的 `<img>`，不会出现裂图。

### 记录表：C1「教程」冒险改回 3 格

记录表的冒险条目按**槽位预设**渲染格子数，而 C1 的「教程」写的是 `["教程", "Tutorial"]`，
落到默认预设（α、两个空格、Ω）**4 格**；规则上教程只有 **3 格**。

- 新增 `three` 预设：α、1 个空格、Ω；
- C1 的教程项改为 `["教程", "Tutorial", "three"]`；
- `markAdventureFromSurvey()` 的中间格选择同步支持 `three`（只留 `mid1`），否则从主控台
  「考察」跳转过来时会把教程标到不存在的第 4 个格子上。

其余循环的冒险条目不受影响（`default` 仍是 4 格、`five` 5 格、`ten-thousand` 10 格）。

## 下载

Windows、macOS、Android 请下载下方对应安装包。便携版请解压到新目录，并保留旧版本的 `data/` 和本地素材
目录（图片、故事数据、`assets/bgm/` 音频都不在安装包里，需要自备）。

本版是补丁版，**存档与资料包格式都没有变化**，可以直接覆盖升级：解压到新目录后把旧目录的
`data/` 与本地素材目录搬过去即可。

Docker 镜像同步发布 `2.0.2` 标签，并把 `latest` 移到本版：

```bash
docker compose pull
docker compose up -d
```

> 用 Docker 部署的话，本版新增的 `app/assets/cycle-symbols/` 目录可以在安装后自己放图标进去
> （5 个文件名见 `tools/packaging/docker/README.txt`）；不放心目录是否已建出来，重跑一次
> `tools/install-docker.sh` 即可。

Android 沿用现有签名策略：未配置发布签名密钥时提供 Debug 签名 APK。不同构建的签名可能不一致，无法保证
覆盖升级；卸载会删除应用内账号、存档和素材，升级前请确认数据可恢复。

资料包为本地私有产物，不进仓库、不进安装包；仓库的 `.gitignore` 已排除 `*.atopack` 与
`official-assets/`。
