## 更新

本版修复 Android 发布流程的签名配置检查，开始使用仓库中已有的固定签名密钥；缺少密钥时停止发布，不再发布临时 Debug 签名 APK。后续版本将沿用同一密钥，保持包名并递增版本号，以支持覆盖安装。

游戏内容更新涉及重大剧透，因此不做介绍。

建议 C4 及以后玩家更新，并同时更新资源包。

## 下载

在本页附件中下载对应平台的安装包。

**安卓升级注意：** 之前从 GitHub 下载的临时签名 APK（包括 2.0.4）可能无法被本版覆盖，提示“签名不同”时不要直接卸载。卸载或清除应用数据会删除账号、存档和已导入的素材。请先确认存档备份可恢复，再进行迁移；素材需要另外保留资源包并重新导入。

**旧版导出注意：** 2.0.4 及更早版本可能显示“已下载”却没有真正保存文件。新版支持系统文件选择器导出，但如果签名冲突，不能先安装新版来修复旧版的导出。找不到导出的 JSON 文件时，请保留旧应用，先解决存档提取问题。

公开安装包不包含本地游戏素材、故事书、音乐、资料包或用户存档。
