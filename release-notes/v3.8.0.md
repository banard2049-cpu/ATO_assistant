# ATO Assistant 3.8.0 · 重大更新

本次更新扩展战役自动结算能力，集中修正战斗奖励、探索卡延迟效果与故事表格显示。

## 战役与科技自动结算

- 新增结构科技结算与统一操作入口，支持资源支付、能力启用、冷却、到期收益和来源提示。
- 完善探索、航行、交涉、调查及侦察流程，关联当前地图位置和已有战役记录。
- 增强重复操作保护与共享状态同步，减少重复扣费、重复领取和多页面结算冲突。
- 改善孵化选择、来源说明、速度与状态处理，并补充命运、追击和战役状态显示。

## 战斗奖励修正

- 修复卡牌提供的基础战利品遗漏，正确合并卡牌奖励与伤害阶段奖励。
- 修正共用牌堆的等级筛选、奖励分组及额外抽牌顺序。
- 修复部分核心资源写入旧字段后不显示的问题；兼容恢复已有记录，避免重复迁移。
- 完善后续循环的资源结算、记录显示及装备奖励提示，并补充覆盖各类战斗卡牌的回归检查。

## 探索与地图体验

- 探索卡的后续提醒采用与特殊地块一致的交互，显示实际来源；点击遭遇左侧完成框时一并清除已到期提醒。
- 今日战斗提醒显示在地块效果之前；探索卡提醒改为黑灰色系。
- 统一探索结算提示与卡牌效果字号，缩小按钮文字；可自动登记的延迟效果使用“自动结算”样式。
- 完善地图标记、捕获结算、地块查找及最近访问地点同步，改善窄屏布局。

## 故事与存档

- 修复故事奖励表、骰子表及竖线表格的识别与显示，并改善第二屏和章节标题兼容。
- 加强战役存档接口、状态合并与跨页面同步，补充相关回归测试。

程序更新不包含个人存档及游戏图片、故事、音频等资料；已有资料与战役存档继续保留。
