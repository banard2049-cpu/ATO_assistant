# ATO Assistant 3.8.7

优化主控台科技能力面板，修正日期推进、英雄回忆保存、探索结算和泰坦修复流程。

## 更新

- 主控台科技能力按用途分组，默认显示紧凑的名称、简介与状态。展开后查看代价、效果、到期日期、卡图和操作；宽屏支持两栏，窄屏保留单栏，并在面板刷新后保留展开状态。
- 科技能力存在可支付的有效组合时，即使尚未选择目标或兑换项目，也会显示“可使用”；实际执行仍须完成选项。无需填写参数的单项能力使用更紧凑的浅色布局。
- 进入下一天前先确认当天进度已保存，再推进日期并保存新一天。连续点击不会重复跳日，保存失败或期间切换账号、档案时会提示并中止相应操作。
- 英雄回忆进度以服务端确认的保存结果为准，增加账号与会话校验、冲突重试及失败提示，避免未保存的进度被误认为已完成。
- 探索卡的选项和手动效果处理完成后，再结算追踪并结束探索，确保追踪依据最终的命运与外交状态计算。
- 同名残废泰坦合并后保留目标关系，已排定的修复事项可继续找到合并后的泰坦。
- 其他界面与流程稳定性修复。

## 下载与升级

在本 Release 的 Assets 中选择 Android APK 或 Windows／macOS 便携包。Docker 使用 `ghcr.io/banard2049-cpu/ato_assistant:3.8.7`，正式版同时更新 `latest`。

程序包不包含个人存档及游戏图片、故事或音频资源；已有战役存档继续兼容。

## 验证

980 项 JavaScript 回归测试、8 项 Python 回归测试以及发布资源审计、附件规则和打包排除检查通过。Android、便携包和 Docker 镜像由本标签对应的 GitHub Actions 构建发布。
