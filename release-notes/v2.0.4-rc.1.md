# ATO Assistant 2.0.4-rc.1 预发布报告

本次预发布基于 2.0.3，集中改善战斗操作，并包含故事卡窗口和素材打包工具的更新。

## 更新

## AIBP 战斗操作

- **AI、BP 独立撤销**：可以越过另一类操作连续回退，各保留最近 30 步，按钮显示剩余步数。牌堆与撤销记录一起保存，刷新后可继续撤销。
- **联动结算分别回退**：BP 结算引起 AI 晋升时，两边分别保留撤销记录。回退一边不会直接用旧快照覆盖另一边的牌堆。达哈卡共用同一副实体 AIBP 牌，仍按共用牌堆规则撤销。
- **BP 暴击按钮放开等级限制**：BPⅠ、Ⅱ可以点击“暴击”，按普通击败结算；BPⅢ保留原有暴击结算。同步调整主界面、卡牌放大窗口和特殊使徒的对应按钮。没有待结算卡牌时仍禁用。
- **地形双击选中**：双击地形选中，再次双击取消；单击地形不再选中或触发地形移动。视线判断模式仍可单击地形所在位置设置来源或目标。
- 开启新战役会清空当前使徒的撤销记录；升级前未保存的旧操作历史无法补回。

## 故事卡窗口

- 调整故事卡与知识面板的布局，卡面随可用高度缩放，为标题、进展和推进／回退按钮预留空间。
- 窄屏下压缩知识面板布局，减少内容超出窗口的情况，小屏仍可滚动查看。

## 素材包工具

- 民间版、官方版打包命令新增 `--incremental-from`，可指定上一份 `.atopack` 作为底包，复用符合源文件指纹及编码策略条件的成员，减少重复处理。
- 包清单记录源文件大小、修改时间、图片质量策略和复用统计；图片质量或豁免策略不一致时回退到全量处理。底包损坏或缺少有效清单时明确报错。
- 保留 `.partial` 写入和发布前校验流程，产物仍是可完整导入的资料包。
- 为超时先知、伊卡洛斯鹰身女妖的两张官中大幅特性卡补充图片压缩豁免规则。

## 验证报告

- JavaScript 回归测试 **121 项通过**，其中包含 10 项 AIBP 撤销测试，覆盖交替操作、各 30 步、刷新恢复、联动晋升、观星取消、新战役及达哈卡共用牌堆。
- 战斗视线与第二屏覆盖测试 **114 项通过**。
- 素材包测试 **19 项通过**，包括增量／全量成员一致性、源文件变化、编码策略切换、损坏底包和导入往返。
- 主控台与 AIBP 页面内嵌脚本，以及修改的独立脚本通过语法检查；公开发布文件审计通过。
- 本地浏览器实测通过：单击不选地形、双击选中／取消、单击其他地形不误移动，以及视线模式点选。
- BP 验证通过：Ⅰ／Ⅱ暴击与击败结算一致，Ⅲ保持原有双重损伤与晋升处理，无卡时按钮保持禁用。
- 未进行 Windows／macOS／Android 安装包的实机安装验证；故事卡布局本次完成源码与语法检查，未覆盖全部屏幕尺寸。

## 下载与升级

Windows、macOS 和 Android 安装包由 GitHub Actions 构建，实际产物以本页附件为准。便携版建议解压到新目录，保留旧版 `data/` 和本地素材。

Docker 镜像版本为 `2.0.4-rc.1`，提供 `linux/amd64` 和 `linux/arm/v7`。这是预发布版，不更新正式版 `latest`。需要试用时，在 Docker 安装目录的 `.env` 中设置 `ATO_VERSION=2.0.4-rc.1`，再执行：

```bash
docker compose pull
docker compose up -d
```

Android 沿用现有签名策略；未配置发布签名密钥时使用 Debug 签名。卸载会删除应用内账号、存档和素材，请在需要卸载重装前保留可恢复的数据。

本次公开发布仅包含程序源码及程序安装包，不上传本地游戏素材、故事书、音乐、资料包或用户存档。2.0.3 提醒的官方故事书勘误仍需从原获取渠道另行更新。
