## 更新

本次把 1.2.11 之后的所有改动合并发布：主控台背景音乐（新功能）＋ 第二屏故事文本显示修复 ＋ Docker / NAS 更新不到位的一串修复。

### 第二屏

- 修复「官方版条目没有对应扫描图时，第二屏只剩标题、正文一片空白」：这类快照以前会清空正文却不渲染任何图，现在自动退回正文；确实没有图也没有正文时，也会明说「该条目暂无对应的官方扫描图与正文」，而不是留一片空白。
- 故事文本同步失败会重试并把原因留在第二屏开关的提示里（检查登录状态或稍后重试），不再静默失败。
- 快照迟到或没写进来时，第二屏保留上一屏内容，不再被阅读器视角的「请先在故事书中选择一个段落。」顶掉已经显示的文字。
- 切换第二屏显示模式失败（例如第二屏没有为当前账号开启）现在会明确报错并说明原因，不再「勾了没反应，屏上还是地图」。

### Docker / NAS

- 修复「主控台更新了、第二屏还是旧版」：容器此前把宿主机的 `app/ss` 整棵目录挂进来，把镜像里的第二屏前端（`index.html` / `app.js` / `styles.css` / `terrain-data.js`）全部遮住，`docker compose pull` 永远更新不到它们。现在容器只挂本地素材（决战版图底图、地形图、地形卡），程序一律由镜像提供，`pull` 能真正完整更新。
- 修复背景音乐在 Docker 上完全没声音：以前 `assets/bgm` 根本没有挂载，音频放进 `app/assets/bgm/` 容器看不到。现在挂载 `app/assets/bgm/audio/`，`bgm.js` 与 `manifest.js` 仍由镜像提供（这样 `pull` 也能更新播放器）；安装脚本会把旧位置平铺的音频自动搬进 `audio/`。
- `pull_policy` 改为 `always`：镜像标签 `latest` 是会移动的，用默认的 `missing` 时 `docker compose pull` 可能认为「本地已有同名镜像」而什么都不拉，更新看起来成功、实际还在跑旧版。
- 决战版图底图是单文件挂载：文件缺失时 Docker 会建一个同名目录顶上去、版图背景静默失效，现在缺文件会直接报错；安装脚本会先放一个 0 字节占位文件，把真正的底图覆盖过去即可（文件名不变）。
- 安装脚本会建好全部挂载点，并提示第二屏幕地址 `/ss/`。需要 Compose 2.17 或更新版本（用到了 `bind.create_host_path`）。

### 主控台背景音乐（1.2.11 之后新增）

- 「用户与存档」下方新增「背景音乐」面板：默认跟随「今日流程」自动切曲，共 18 个情境阶段——航行、紧迫、探索、考察、城邦、战斗、军械库、发展、泰坦柱廊、主线、回忆突破、内蕴、法洛斯、灾祸、低谷、结算、休整、终局；换曲为 1 秒交叉淡入淡出。
- 流程里的移动 / 探索 / 考察 / 遭遇 / 发展 / 故事 / 灾祸步骤自动对应阶段；今天没发生的事（没战斗、没冒险、没灾祸）会被跳过，跳着勾选也能落到正确阶段。
- 阶段可以手动锁定；「故事」的主线 / 回忆突破 / 内蕴奥德赛 / 法洛斯之梦 / 特殊事件入口、「考察」里的冒险中枢与 R&R、战斗模块按钮点一下会临时切曲，这天流程阶段一变就自动交还自动档。
- 可以导入自选 BGM（存在本机浏览器，不写进仓库也不上传），指定它属于哪个阶段，随时改派或删除。关闭音乐时面板只留一个开关。
- 只有主控台出声：故事模块（story/）不再自己播放音乐，避免两处叠加。
- 音频不进任何安装包，需要自备：便携版 / Android 放进 `assets/bgm/`，Docker 放进安装目录的 `app/assets/bgm/audio/`；文件名清单见 `assets/bgm/README.md`。缺文件时面板会列出缺哪几首，不会静默无声。
- asset-studio 新增「背景音乐」资源通道：导出 .atopack 时可勾选「包含主控台背景音乐」，Android 端导入资料包后会解包回 `assets/bgm/`。
- 发布方式微调：Release 只挂安装包，不再附带 APK 校验和文件。

## 下载

Windows、macOS 和 Android 请下载下方对应安装包。Docker 镜像同步更新至 1.3.1 和 latest：

~~~bash
docker compose pull
docker compose up -d
~~~

便携版从旧版本升级时，请解压到新目录并保留旧的 data/ 目录，登录账号和存档都在其中。

背景音乐音频属于自备素材，不进仓库、不进便携版 / Docker / APK：便携版与 Android 放进 `assets/bgm/`，Docker 放进安装目录的 `app/assets/bgm/audio/`（重跑安装脚本会把旧位置平铺的音频搬过去）。Docker 升级后 `app/ss/` 下的 `index.html`、`app.js`、`styles.css`、`terrain-data.js` 已改由镜像提供，宿主机上的旧副本不再生效，可以直接删掉。

游戏图片、完整故事正文及 atopack 资源包由本地资料提供，不包含在公开发布附件中。

## 验证

- Docker 挂载不变量测试（新增）：拦住「挂载点遮住镜像自带程序文件」这类回归（拿修复前的 compose 验证过会报红），并检查 BGM 挂载点与 `manifest.audioDir` 一致、单文件挂载带 `create_host_path: false`、`pull_policy` 不是 `missing`。
- 背景音乐测试 19 项通过：曲目表完整性、控制台接线、跟随流程 / 手动锁定 / 临时切换回退、ogg 回退、缺文件提示、脚本目录解析、自选导入 / 改派 / 删除 / 持久化、关闭态面板，以及 Docker 的 `assets/bgm/audio/` 回退与「本目录优先」。
- 故事页第二屏测试 12 项通过：官方版有扫描图才只看图、没有扫描图退回正文、没有快照时保留上一屏内容、快照写失败重试并留痕、模式切换失败把服务端原因交回页面。
- 第二屏地图显示、第二屏视线镜像、第二屏地形数据三套测试通过；打包排除规则与发布资产规则测试通过；PHP 语法检查通过。
- 端到端（本地 PHP 服务）：第二屏没有为当前账号开启时，切换显示模式返回 409 并带原因，不再假装成功；开启后切到「故事文本」能写进存档并被第二屏读到。
- 便携版与 Android 安装包在打标签时由 CI 构建，Docker 镜像同步推送 1.3.1 与 latest。
