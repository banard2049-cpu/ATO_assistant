# ATO Assistant 3.8.10

记录表 Boss 头像、地图隐藏数字与蒙版修复、探索结算性能、故事书按需加载，以及一批 APK / Docker 打包修正。

## 更新

### 记录表

- 「敌人」面板新增 19 张 Boss 头像（512×512 透明 PNG，从官方 AI 卡背直接提取，未重绘）。
- 头像文件缺失时不显示破图：标题退回纯文字，不占图标列、不重复请求缺图；没有映射的 Boss 也不会生成图片元素。
- 头像已登记进素材清单，随 .atopack 分发；旧 APK 的内置名单不认识这些条目，需先更新到 3.8.10 再导入新包。

### 地图

- 补全 C1:066 与 C2:002 的隐藏数字，复核全部 511 个图面；数字直接排入透明蒙版，保留字形内部透明空洞。
- 重描 21 张合并透明蒙版：修复 14 处密码牌、C4:027/028/079 的字母框邻接标牌、C5:040 的 039 β 标牌、教程 T04→T05 出口等；底图及其余蒙版字节保持不变。
- 全量漏图审核未发现上一轮 40 处补录之外的新遗漏。

### 探索与结算

- 「一键结算」「结算完毕」合并流程区刷新，减少重复渲染；追踪结算改为等宿敌被故事事件引入后再算，未引入时只显示数量并提示忽略。
- 避免主控台响应自身保存广播后再次读取存档；复用已确认保存的数据和版本号；折叠的探索卡库和暂时移出牌堆改为展开时加载。
- 真机对照中，「结算完毕」点击到下一帧的中位耗时约从 306 ms 降到 248 ms，每次少读一份约 1.28 MB 的存档响应。

### 卡片与故事书

- 43 张 AIBP 倾斜卡校正 0.30–1.63°，49 张探索卡顶边避免额外 2–3 像素裁切并保留修正标记。
- 故事书官方正文、人物小传索引和混排 mapping 改为按需加载：民间版首屏不再解析十几兆的官方数据，切到官方版或打开人物小传时才读入，降低安卓 WebView 的首屏内存压力。
- 第二屏故事显示与相关样式同步修正。

### APK 与 Docker

- APK：内置资料包名单加入 19 条 Boss 头像映射；AtopackStore 对大文件响应显式给出 Content-Length 并禁用缓存，避免故事书大文件被整段缓冲。
- Docker：`record/assets` 整棵挂载，覆盖新增的 `record/assets/boss-avatars/`；补充挂载说明与显式回归断言，防止以后拆成只挂子目录。
- 记录表页面在缺头像时不再显示错误占位。

## 资源包

两版 `.atopack` 已按分层地图 + Q85 重新构建，均包含 19 张 Boss 头像：

- `ATOassets-民间版-分层地图-q85-2026-10-22-v3.8.10-rc.1-r1.atopack`：1.51 GiB，4917 个成员。
- `ATOassets-官方版-分层地图-q85-2026-10-22-v3.8.10-rc.1-r1.atopack`：2.62 GiB，7114 个成员。

两包通过打包器 `full` 校验与 `check_pack.py --crc --hash`；头像、1302 张地图 PNG 均与工程原字节一致。官方版首轮重打时发现官中图会按同名 stem 把使徒大卡顶替成头像，现已修正并加回归。**更新程序后请重新导入新资料包。**

## 下载与升级

在本 Release 的 Assets 中选择 Android APK 或 Windows／macOS 便携包；Docker 使用 `ghcr.io/banard2049-cpu/ato_assistant:3.8.10`，正式版同时更新 `latest`。Android、便携包和 Docker 镜像由本标签对应的 GitHub Actions 构建发布。

程序包不包含个人存档及游戏图片、故事或音频资源；已有战役存档继续兼容。
