## AIBP Trait 与 Token 加载优化预发布

本次预发布改进 AIBP 的卡片选择加载，并延续 v1.3.7-rc.1 的旧版 Docker Compose 兼容支持。

### 更新内容

- 通用及周期专属 Trait 优先于 Boss 卡图探测加载，减少打开选择窗口后长时间看不到通用卡的问题。
- 为「逆行动量」（CT1326）补充名称索引，仅在 C3 Boss 的 Trait 列表显示；超时光先知、伊卡洛斯鹰身女妖、太阳后裔可见，THE_BURDEN 需要当前战役为 C3。「恶毒」仍在所有周期可选。
- Token 优先使用图片清单；清单不可用时尝试目录列表，两者都不可用才探测常见文件名。已有清单时不再产生大量无效图片请求。
- 防止过期的 Token 目录加载结果继续发起图片请求。

### 升级与素材

- 更新程序后刷新 AIBP 页面，再打开 Trait 或 Token 选择窗口。
- 「逆行动量」需要自行提供图片，位置为 `aibp/ps/other/trait/COMMON_TR_002.jpg`。公开安装包不包含卡图、音频或个人存档。
- 使用自备 Token 素材时，新增图片后请同步维护 `aibp/ps/other/token/token_manifest.js`；有效清单存在时不会额外扫描未列出的文件。
- 更新前备份并保留原有 `data/` 和素材目录；便携版建议解压到新目录后迁移数据与素材。

### Docker 与安装包

- 继续提供旧版 `docker-compose` 1.21.0+ 使用的 `compose.legacy.yaml`。
- Docker 预发布镜像标签为 `1.3.7-rc.2`，不更新稳定版 `latest`；预构建架构为 `linux/amd64` 和 `linux/arm/v7`。
- 沿用现有 Windows、macOS、Android 和 Docker 自动打包流程。
- Android 未配置发布签名密钥时使用 Debug 签名，不保证覆盖升级，请先备份数据。

### 验证范围

- Token 回归检查覆盖清单加载、目录回退、无清单探测和过期请求取消。
- 已检查 C1–C5 通用 Trait 的显示筛选及现有 C4/C5 Trait 配置。
- 浏览器实测未完成，本版本仍为预发布；加载改善需在实际部署环境确认。
