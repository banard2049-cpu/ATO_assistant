# ATO Assistant 2.0.5 发布说明

本版包含 [2.0.5-rc.1 的更新](https://github.com/banard2049-cpu/ATO_assistant/releases/tag/v2.0.5-rc.1)，并修复 Boss Trait 卡加载、补充达哈卡 AI/BP 的结算操作。可从 2.0.4 或更早版本升级。

## 附件重打包（2026-09-26）

- Android「导出状态」现在调用系统文件选择器，只有 JSON 实际写入成功才显示完成；取消或写入失败会报错。旧版 APK 曾显示“已下载”却没有保存文件。
- Android 导入 `.atopack` 时，包内缺失、校验失败或当前 APK 不认识的单项资源会跳过，其他有效资源继续安装；结果会显示跳过数量。无效包格式及存储写入错误仍会报错。
- 本次覆盖同名安装附件，版本号仍为 2.0.5；请以本页最新附件为准。

## 更新

## 战斗操作

- 达哈卡共用 AI/BP 牌堆抽出 AI 半区时，现在可直接选择「击败」或「暴击」，按 BP 结算损伤；放大卡图后也可使用相同操作。关闭放大图不再自动弃置这张牌。切换到其他 Boss 时，这两个专用按钮会隐藏。
- Trait 选择弹窗优先加载当前 Boss 自己的 Trait，避免大量无效通用卡图片请求阻塞。探测编号上限与其他卡牌区域统一为 12；现有 Boss Trait 素材的最大编号是 4。

## 包含预发布版的更新

- Cycle V 新增一条 1–7 格的追踪轨：生成、推进、减缓与清空可在主控制台及地图模块操作；旧存档的追踪位置会迁移。追踪对象的名称和触发格数属于剧透，见下方折叠块。
- Cycle V 进入未探索板块时，新板块继承出发板块的 A/B 面；主控制台与地图模块保持一致。
- 地图上的唯一标记现在只保留一个位置，读档时也会清理重复位置；宿敌所在板块不会被「仅看已探索」过滤隐藏。本版另新增一个 Cycle V 标记，名称与素材出处见下方折叠块。
- 「法洛斯之梦」故事标题新增解密按钮及搜索匹配，支持民间版英文标题与官方版中文标题。
- 主控制台的冒险枢纽回忆勾选先保存并重绘，再同步记录，避免刷新后勾选被还原。
- 素材清单从 4298 个面增至 4299 个面。Android 用户若要使用新增标记仍需安装本版 APK；重打包后的导入器会跳过当前 APK 不认识的资源，继续安装其余内容。

## 验证

- 达哈卡共用牌堆测试涵盖 AI 半区击败、暴击、放大图关闭，以及切换 Boss 时按钮隐藏；Boss Trait 素材路径与编号已核对。
- 2.0.5-rc.1 的追踪轨、板块继承、唯一标记、标题解密及素材包验证见[预发布报告](https://github.com/banard2049-cpu/ATO_assistant/releases/tag/v2.0.5-rc.1)。

## 下载与升级

- Windows、macOS 与 Android 安装包由发布工作流构建，实际产物以本页附件为准。资料包（`.atopack`）仍需从原渠道获取，不包含在公开附件中。
- 当前 Android 发布流程若未配置正式签名密钥，将生成 Debug 签名 APK；此类 APK 日后可能无法覆盖安装正式签名版本。卸载会删除应用内账号、存档和素材，请先确保数据可恢复。

公开安装包不包含本地游戏素材、故事书、音乐、资料包或用户存档。
