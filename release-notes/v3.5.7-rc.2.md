# ATO Assistant 3.5.7-rc.2 预发布

本版修复 Android App 内 BGM 与故事书朗读无声的问题，供 Android WebView 环境验证。

## 更新

- BGM 在用户点击开启或切换曲目时立即恢复 Web Audio，避免 Android WebView 因异步加载后错过用户手势而保持静音。
- Android 故事书的浏览器语音选项改用系统中文 TextToSpeech；支持暂停、继续和停止。系统语音不可用时回退到 WebView 浏览器语音。
- 页面浏览器、桌面版及其它平台的朗读路径保持原有实现。

## 验证

- Android APK、便携版和发布检查由推送标签后的 GitHub Actions 执行；请以工作流结果及 Android 真机播放结果为准。
