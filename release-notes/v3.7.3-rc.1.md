# ATO Assistant 3.7.3-rc.1

## 更新

- 记录表的泰坦死亡按钮每次只减少一个泰坦，并将已死亡累计增加 1；数量归零时移除该行。
- 勾选或取消残废每次只改变一个泰坦的状态。多个泰坦时拆分数量，同名残废泰坦自动合并为一行。
- 修正 C3 主界面特殊事件定数框的文字溢出；事件名称支持换行，多勾选框在窄列下与文字分行显示。

本次仅更新程序，继续使用已有存档和游戏资源，无需更换资源包。
