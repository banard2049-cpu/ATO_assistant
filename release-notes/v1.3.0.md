## 更新

- 主控台新增「背景音乐」面板（在「用户与存档」下方）：默认跟随「今日流程」自动切曲，共 18 个情境阶段——航行、紧迫、探索、考察、城邦、战斗、军械库、发展、泰坦柱廊、主线、回忆突破、内蕴、法洛斯、灾祸、低谷、结算、休整、终局；换曲为 1 秒交叉淡入淡出。
- 「今日流程」里的移动 / 探索 / 考察 / 遭遇 / 发展 / 故事 / 灾祸步骤会自动对应阶段；今天没发生的事（没战斗、没冒险、没灾祸）会被跳过，跳着勾选流程也能落到正确的阶段。
- 阶段可以手动锁定，面板里选「自动（跟随今日流程）」即放回自动；锁定状态会一直保留，直到你自己改回来。
- 「故事」步骤的主线 / 回忆突破 / 内蕴奥德赛 / 法洛斯之梦 / 特殊事件入口、「考察」里的冒险中枢与 R&R、以及战斗模块按钮：点一下会把音乐切到对应阶段，并在新标签打开模块，主控台留着继续放；这类临时切换会在这天流程阶段变化时自动交还自动档。
- 可以导入自选 BGM（音频存在本机浏览器里，不写进仓库也不上传），导入后指定它属于哪个阶段，也能随时改派或删除。
- 关闭音乐时面板只留一个开关，阶段、音量、导入和曲目列表一并收起。
- 音频不进任何安装包：请把音频（.mp3 或 .ogg）放进 assets/bgm/ 目录，或运行 tools/install-bgm.bat 从本地音乐目录安装；文件名清单见 assets/bgm/README.md。缺文件时面板会列出缺哪几首，不会静默无声。
- 只有主控台出声：故事模块（story/）不再自己播放音乐，避免两处叠加。
- asset-studio 新增「背景音乐」资源通道：导出 .atopack 时可勾选「包含主控台背景音乐」，把 assets/bgm/ 的音频一起带走；Android 端导入资料包后会解包回 assets/bgm/。
- 发布方式微调：Release 只挂安装包，不再附带 APK 校验和文件。

## 下载

Windows、macOS 和 Android 请下载下方对应安装包。Docker 镜像同步更新至 1.3.0 和 latest。

便携版从旧版本升级时，请解压到新目录并保留旧的 data/ 目录，登录账号和存档都在其中。

背景音乐音频属于自备素材，不进仓库、不进便携版 / Docker / APK，只在使用者自己准备音频、或自行导出 .atopack 资料包时才随之流转。

游戏图片、完整故事正文及 atopack 资源包由本地资料提供，不包含在公开发布附件中。
