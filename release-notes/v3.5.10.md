# ATO Assistant 3.5.10

本次正式版包含 `3.5.10-rc.1`、`3.5.10-rc.2` 的全部更新，并进一步改进 AIBP 卡图加载、战斗结算、阿尔戈号记录表和 Android 资源导入。以下说明省略 C4/C5 的剧情、角色及具体战斗内容。

## 更新

### AIBP 图片与同步

- 卡图按实际已安装的图片清单加载，支持不同图片格式及正反面；不再逐个请求猜测出的文件名，减少无效请求和 404。网页、便携版、Docker、Android 本机和局域网第二屏使用相同原则。
- 移除可选卡图等待全部主图加载的旧限制。大卡尚在加载时，其余卡图可开始读取，避免被单张大图拖住；保留图片加载优先级和异步解码。
- 补全固定素材清单，并统一素材库、资料包打包和 Android 导入使用的条目。Android 需更新 APK，才能识别新增的资料包条目。
- 修复删除自定义特性后，第二屏同步读取无效条目导致的异常；同步失败显示完整错误，便于定位问题。

### 战斗与战利品

- Boss 等级属性改由统一数据维护，修正部分等级属性与加成处理；等级变化时保留手动标记和已有战斗进度。
- 新增「秒杀 Boss」操作，在完成相关规则处理后补足剩余伤害，并可通过一次撤销恢复。
- 战利品计算支持按战斗场景、结果和奖励选择结算，补充遗漏的资源与提示；需要选择的奖励未完成时阻止入账。
- 改进结算界面的数字加减操作与写入状态，结算过程中锁定输入，避免结果变更造成错误入账。
- 修复部分战斗中刷新后未完成操作无法继续的问题，并统一主页面与第二屏的伤害、伤口显示。

### 阿尔戈号记录表

- 减少资源区小卡图的重复创建与加载，数量更新时复用已有图片；资源图采用主动加载，改善刷新后的显示。
- 修正 C2 船员区容量：未解锁为 8，解锁后为 9，船员、难民与俘虏共同计入上限。
- 「计数标记」改为名称和数量组成的紧凑列表。标题右侧「＋」可新增，支持修改名称、数字、加减和删除；数量最低为 0，各循环独立保存。
- 新增框默认收起，加减图形保持居中；旧存档中的计数文字自动移到对应循环的战役笔记开头，以「【原计数标记】」标明来源，保留既有笔记，重复加载不会重复迁移。
- 修复 PHP 将空循环对象编码为数组后，新计数与笔记在保存时消失的问题。

### 主控台与知识等级

- C1 内蕴奥德赛的阿尔戈号知识起点由 1 修正为 0，主控台、战役简报与官方 `.jsave` 导入同步修正。最低可回退到 0，重新加载后保持 0；故事入口提示显示实际知识数值。其他循环的正确起点保持不变。
- 保留已有存档的知识等级，避免误减实际已获得的知识；尚未开始的 C1 存档可回退一次调整到 0。
- 翻译版本按钮显示当前启用的「官方翻译」或「民间翻译」，同步更新各模块脚本缓存版本。
- 「重置今日」增加确认提示。取消时保留全部状态；确认后清除今日流程和事件的完成标记，保留日期、笔记和事件列表。「进入下一天」调整到右侧。

### Android 导出、保存与开发工具

- 战役简报 ZIP 和英雄存档 JSON 使用系统文件保存入口；简报包含地图 GIF、科技 GIF 和逐日 PDF。系统确认写入成功后才显示导出完成，取消或失败后可重试。
- 修复本地图片污染 WebView Canvas 导致 GIF/PDF 无法导出的问题，图片及科技树 SVG 使用独立数据进行导出。
- 本机存档、账号切换、退出登录及备份采用同步提交，写入失败返回错误，降低进程结束后数据丢失的风险。
- 增加项目专用 Android 模拟器工具与真实 WebView 回归入口，覆盖导入、逐日备份、恢复前一天、附件、账号隔离、第二屏及重启后的持久化。

## 下载

- Android：`ATO-Assistant-3.5.10.apk`。
- Windows：`ATO-Assistant-Portable-3.5.10-windows-x64.zip`。
- macOS：`ATO-Assistant-Portable-3.5.10-macos-arm64.zip` 与 `ATO-Assistant-Portable-3.5.10-macos-x64.zip`。
- Docker：`ghcr.io/banard2049-cpu/ato_assistant:3.5.10`；正式版同时更新 `latest`。

安装包由 GitHub Actions 构建并上传至本次发布，镜像发布至 GHCR。程序包不包含游戏素材；已有资料包与存档可继续使用，新增素材条目需配合更新后的程序。
