# ATO Assistant 3.5.9

本版为阿尔戈号记录表加入图片附件，并补齐 Android 的战役简报支持。

## 记录表图片附件

- 「战役笔记」下方新增图片附件区。点击右侧「＋」展开菜单，可从相册、文件选择图片，或调用摄像头拍照；也支持拖入图片和粘贴截图。
- 图片按当前账号、循环保存。点击缩略图放大，直接编辑图片下方的名称即可改名，也可删除附件。
- 附件样式沿用记录表的字段配色和边框，仅显示图片与名称，不显示尺寸、文件大小等信息；加号固定在按钮中心。
- 添加时自动压缩为 JPG，最长边不超过 2048 像素，每张不超过 768 KB。图片单独保存，日常存档同步只传递附件引用，避免图片撑大保存请求。
- 主控台完整存档和记录表单独导出均包含图片，导入时恢复附件。Android 的记录表导出使用系统文件保存入口。
- 多页面同时添加或删除附件时按引用合并；账号切换后拒绝把旧页面图片写入新账号。

## Android 战役简报

- Android App 可读取本机每日备份并生成战役简报；手机开启第二屏幕后，局域网设备也可打开简报。
- 简报按所选档案、循环回放当日的地图、科技、英雄、故事和卡牌进度，避免把今天的状态混入历史记录。
- 增加 Android 与 PHP 简报结果对照测试，并将本机存档、附件和简报检查接入发布流程。

## 验证与使用说明

- 已在浏览器验证附件添加、菜单、放大、改名和刷新恢复；附件保存、账号隔离、并发合并、备份导入导出及 Android 本机存储均有回归检查。
- Android、Windows、macOS 安装包和 Docker 镜像由 GitHub Actions 构建。相册、相机入口由设备提供；Android 拍照仍需实机验证。电脑浏览器调用摄像头需要 HTTPS 或本机地址，并允许相机权限。
- 更新前建议导出存档。手动迁移便携版或 NAS 时请复制整个 `data/` 目录，包含 `record-attachments/`；删除附件只移除当前记录中的引用，图片文件保留供历史备份恢复。
