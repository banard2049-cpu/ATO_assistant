# ATO Assistant 3.8.4

**本次修复了资源计算 bug，建议所有用户更新。**

## 更新

- 修正部分资源的种类、数量与等级附加奖励计算，确保结果展示、复制和记录表入账一致。
- 战利品等级倍率默认读取记录表，仍可在结算弹窗手动调整；战斗中的临时等级调整不再影响自动填写。
- 修复部分晋升与弃牌重洗流程，保持牌堆状态和结算结果一致。
- 修复新获得单位错误继承已有异常状态的问题。
- 修复并发同步进度时，将已退休或删除的角色重新加入队伍的问题。
- 校正部分科技类别、功能标签与适用范围，改善筛选和解锁后的显示。
- 整合 3.8.4-rc.1 的存档导入导出、编辑保存、并发校验、第二屏显示及语音停止修复。

本次修复影响更新后的操作与结算，不自动追溯调整已有存档的资源余额。已经完成的旧结算如需核对，请只修正差额，避免重复计入整场奖励。

## 下载与更新

在本 Release 的 Assets 中选择 Android APK 或 Windows／macOS 便携包。便携版也可使用程序内的「检查更新」。Docker 使用 `ghcr.io/banard2049-cpu/ato_assistant:3.8.4`，正式版同时更新 `latest`。

程序更新不包含个人存档、图片、故事或音频资源；已有战役存档继续兼容。

## 验证

发布前执行 JavaScript 回归、科技分类与发布打包检查，并检查脚本语法和 Git 差异。新增回归已加入持续集成；正式安装包与 Docker 镜像由本标签的 GitHub Actions 构建发布。Android 尚未进行真机验证。
