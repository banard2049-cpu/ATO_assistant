# ATO Assistant 3.8.4-rc.1

本预发布版本修复存档导入导出、故事编辑保存和多设备并发操作中的六项功能问题。

## 更新

- 无法读取服务器完整存档时停止导出，避免生成缺失模块的“完整备份”。恢复旧版断网生成的不完整备份时，仅恢复文件中已有的状态，保留其他模块当前数据。
- 英雄页导入后自动同步到当前登录账号，保留当前会话的版本与保存基线；读取文件期间切换账号时停止导入。
- 素材库拆分、合并故事段落前等待全部编辑保存，按顺序处理连续修改；保存失败时停止结构操作，避免旧请求覆盖新正文。
- Android 原子提交同时校验科技、英雄、地图等只读依赖的版本；依赖发生变化时拒绝整笔写入。
- 特殊抽牌后第二屏正确切换当前 AI／BP 卡牌。
- 云端语音合成及句间等待期间，点击“停止”会结束整次朗读，迟到的音频不再继续播放。

## 下载

在本 Release 的 Assets 中选择 Android APK 或 Windows／macOS 便携包。Docker 使用 `ghcr.io/banard2049-cpu/ato_assistant:3.8.4-rc.1`。

安装包与镜像由本标签的 GitHub Actions 构建并上传。本版本为预发布版本，Docker 的稳定版 `latest` 保持不变。

程序更新不包含个人存档及游戏图片、故事和音频；已有战役存档继续兼容。更新不能恢复此前已经被覆盖或删除的数据。

## 验证

121 项相关 JavaScript 回归测试通过，Android 导入 184 项检查通过；修改脚本的语法检查与差异检查通过。新增回归已加入持续集成。Android 尚未进行真机验证。
