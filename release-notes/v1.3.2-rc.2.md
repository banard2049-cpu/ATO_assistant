## 更新

> **这是预发布版本（rc）**，在 1.3.2-rc.1 的基础上新增 arm/v7 支持。如果你不用树莓派或 32 位 ARM 设备，功能与 1.3.2-rc.1 完全一致，无需专门升级。

### Docker 镜像新增 linux/arm/v7（32 位树莓派）

- 之前公开镜像只发布了 `linux/amd64`：**32 位的 Raspberry Pi OS 拉取时会直接提示平台不匹配**（`no matching manifest for linux/arm/v7`），无论怎么配都跑不起来。现在同一个标签同时指向 `linux/amd64` 与 `linux/arm/v7`，Docker 会按本机架构自动选择，命令与 x86 服务器上完全一样，不需要加 `--platform`。树莓派 3/4/5 装 32 位系统时直接拉取即可。
- 其它架构（`linux/arm64`、`riscv64` 等）没有预构建镜像，一键安装脚本在这种情况下**不再停在 `no matching manifest`**：它会取对应版本的源码，用发布镜像的那份 `Dockerfile` 在机器上本机构建，并把 `compose.yaml` 指向本地镜像、把 `pull_policy` 改成 `never`（本地镜像不在任何 registry 里，留着 `always` 会去拉一个不存在的东西）。
  - 64 位的 Raspberry Pi OS 属于 `linux/arm64`，走的就是这条本地构建路径。想省掉自己构建，装 32 位系统用现成的 arm/v7 镜像更省事。
  - 升级方式：本地构建的镜像重跑一次安装命令即可（`docker compose pull` 对本地镜像没有意义）。
- 只做了架构层面的改动：`Dockerfile` 一行没动，基础镜像 `php:8.4-cli-alpine` 本来就有 arm32v7 清单，应用是纯静态文件加 PHP 内置服务器，两边的行为一致。**本次预发布的主要验证目标就是 arm/v7 那份镜像能真的构建出来**，请拿到树莓派后回报结果。

### 1.3.2-rc.1 的内容一并包含

本版本包含 rc.1 的全部改动，此处不重复；完整清单见 [v1.3.2-rc.1 发布说明](https://github.com/banard2049-cpu/ATO_assistant/releases/tag/v1.3.2-rc.1)。要点：私有文件（`data/`、密钥、存档）不再可下载、局域网多账号不再串档案、讯飞在线语音合成在 `http://` 局域网地址下可用、资料包导入与安装的路径校验。

## 下载

Windows、macOS 请下载下方对应安装包。Docker 镜像同步更新（`latest` 标签不指向预发布版，用预发布版本请在安装目录的 `.env` 里写明版本号）：

~~~bash
# .env
ATO_VERSION=1.3.2-rc.2
~~~

~~~bash
docker compose pull
docker compose up -d
~~~

32 位树莓派（Raspberry Pi OS 32-bit）不需要写 `--platform`，直接按上面两条命令拉取即可拿到 arm/v7 镜像。

便携版从旧版本升级时，请解压到新目录并保留旧的 data/ 目录，登录账号和存档都在其中。**升级后请确认 `data/` 不在任何静态目录里对外暴露。**

**本次预发布带 APK**：仓库已配置 Android 发布签名密钥，APK 会作为发布附件一起产出（versionCode 低于正式版 1.3.2，正式版发布后可以正常覆盖升级）。Android 用户可以装这个预发布版试；只想用稳定版的话继续用 1.3.1 即可。
