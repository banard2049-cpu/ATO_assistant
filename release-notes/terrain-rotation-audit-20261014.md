# 地形旋转核对（2026-10-14）

须目刻托斯之战的 Lightwall 1x5（R10 C15）由 rotation 180 / flipped false 修正为 270 / true，对应屏幕顺时针 90°、竖向占据 R8–R12 C15，不再与 R10 C12 的 Arcology 重叠。适用于等级 1–4。

根因：`tools/parse-tts-lua.cjs` 误把声明 `key` 的循环全部当作按索引分支。没有 `if key == …` 的循环因此丢失直接传给 `takeTile` 的旋转与翻面参数。现已读取这些循环的公共参数，并重新生成两份 TTS 参考 JSON。

核对了本地 8 份 Battle Setup Lua 中的 34 个配置函数，并运行转换脚本对现有 31 个战斗/等级组合的比对。此次导入修正改变 14 条参考记录，其中 6 条在应用配置中已有独立修正；新增修正共 8 片：

- 须目刻托斯之战：1 片 1x5 光墙，竖放且翻面。
- 福波斯之龙等级 1–2：R1 C11 的 1x5 光墙翻面。
- 负重者 `burden-battle` 等级 1–4：3 片 Cliff O 旋转从 180 改为 0。
- 负重者 `hardest-to-bear`：3 片 Cliff O 旋转从 180 改为 0。

其余 TTS/应用差异未直接覆盖：已有测试锁定的 L 形地形修正、严酷教训河道修正、Timefront 城市基底/锚点补全，以及解析脚本未完整识别的金羊轨道名称分支。上述差异不能仅凭本次导入结果认定为新错误。

未编辑的旧预设在读取存档时自动更新，保留显示选项与地形 ID；移位、增删等自定义布置保留。主屏与第二屏的脚本缓存版本同时更新。

验证：新增 3 项回归通过，覆盖原始 Lua 参数、8 片修正及各适用等级、旧预设迁移与编辑保留、光墙竖向占格/光照来源及城市不重叠。既有 terrain-data、battle-map control 测试通过；视线测试 115/115 通过；`git diff --check` 通过。第二屏地图集成测试因环境无法启动 PHP 子进程（EPERM）跳过，未完成实际浏览器目视验证。
