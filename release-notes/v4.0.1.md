# ATO Assistant 4.0.1

## 更新

修复故事书「密语记录」中百臂巨人语的图案对应丢失问题。逐个录入多个图案时，保存新的数字对应会保留先前录入的数字，刷新后也能正常读取。旧密文中尚未解读的图案会按新录入的对应自动补全。

更新后，仍保存在战役存档里的对应会恢复显示。已经被覆盖的对应需要重新录入。

## 下载

Android、Windows 和 macOS 安装包请见发布页附件。Docker 镜像为 `ghcr.io/banard2049-cpu/ato_assistant:4.0.1`。

## 验证

使用 PHP 临时战役存档验证了逐个保存、重新读取和旧密文补全。巴别语和塞壬语也通过同样的检查。
