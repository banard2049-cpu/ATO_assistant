## 更新

本版本整合背景音乐切换、故事朗读暂停与继续，以及源码许可证更新。

- 修复 BGM 勾完探索就提前跳到“打造与训练”的问题：自动模式按流程勾选推进，探索 → 考察 → 遭遇 → 发展，不再因没有待办提醒而跳过条件步骤；今日流程全部完成后播放休整曲。
- 理顺 BGM 切换规则：手动锁定优先，自动模式下点击故事 / 考察入口只临时切曲；新增“跟随流程”按钮，立即清除锁定和临时场景。下拉框与状态文字明确显示当前模式，锁定期间点击过的入口不会在解锁后补播。
- 修复 BGM 跨天、重置今日、切换 Cycle 或存档后残留临时场景的问题；普通界面重绘保持当前音乐。同曲切换模式或修改其他阶段的自选曲不会从头重播，快速连续切换以最后一次选择为准，离开探索时氛围层与转场音一并淡出。
- 故事书朗读器在开始朗读后新增独立的“暂停”按钮；暂停后按钮变为“继续”，可从当前位置恢复朗读。“停止”仍会结束本次朗读，播放完成后暂停按钮自动隐藏。
- 暂停与继续同时支持离线语音、云端 / 本地生成音频和浏览器原生语音。云端音频仍在请求时也可以先暂停，音频就绪后保持暂停状态；浏览器原生语音暂停期间不再累计无响应超时。

## 下载

Windows、macOS、Android 请下载下方对应安装包。便携版请解压到新目录，并保留旧版本的 `data/` 和本地素材目录。

Docker 的 `latest` 标签同步更新至 1.3.6。如果此前在 `.env` 中固定了版本，请改为 `ATO_VERSION=1.3.6`，然后运行：

```bash
docker compose pull
docker compose up -d
```

Android 沿用现有签名策略：未配置发布签名密钥时提供 Debug 签名 APK。不同构建的签名可能不一致，无法保证覆盖升级；卸载会删除应用内账号、存档和素材，升级前请确认数据可恢复。

游戏图片、完整故事正文、官中覆盖图片和 `.atopack` 资源包仍由本地资料提供，不包含在公开安装包中。
