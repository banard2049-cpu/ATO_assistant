# ATO Assistant 3.8.10-rc.1

探索结算性能预发布版，重点改善主控制台「一键结算」和「结算完毕」的等待。

## 更新

- 结算完成后合并流程区刷新，减少重复渲染。
- 避免主控制台响应自身保存广播后再次读取存档。
- 复用已确认保存的数据和版本号，减少「结算完毕」时整份存档的重复下载；其他页面修改仍进行版本校验和冲突重试。
- 折叠的探索卡库和暂时移出牌堆在展开时加载，保留切换面板时尚未应用的选牌。

## 验证

真实本机 PHP、大存档副本、3 轮对照中，追加缓存优化使「结算完毕」点击到界面下一帧的中位耗时从 306 ms 降至 248 ms，约减少 19%，每次少读取一份约 1.28 MB 的存档响应。此比较以此前已完成重复刷新优化的代码为起点，并非所有设备上的固定收益。

557 项相关回归测试通过，浏览器对照的资源、牌堆、追踪和结算回执结果一致。测试未改动原存档。本机尚未稳定复现持续数秒的停顿；手动选择阶段等待基本不变。

## 下载

Windows 选择 `windows-x64.zip`；Apple 芯片 Mac 选择 `macos-arm64.zip`；Intel Mac 选择 `macos-x64.zip`。Android APK 和 Docker 镜像由同一标签的发布流程构建。

这是预发布版本，已有战役存档继续兼容。程序包不含个人存档及游戏图片、故事或音频资源。
