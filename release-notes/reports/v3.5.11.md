# v3.5.11 变更与验证报告

日期：2026-10-10（Asia/Shanghai）。基线：`ad8d04369f0965a79d316337cec10bc0b77515c6`，即 v3.5.10 合并后的 main。

## 范围

本次仅发布本轮 Boss 特性、指示物、等级特性弹窗和资源登记清理改动。当前工作区另有愿望区样式与英文术语开发，未纳入本次发布。素材、存档、本地打包缓存和检查产物不进入 Git。

## 验证

- 96 项：`aibp-trait-rules`、`aibp-level-data`、`aibp-default-trait-cancel`、`aibp-image-loading`、`aibp-custom-trait`、`aibp-panel-cards`、`aibp-blackbeak` 与 `tools/test-aibp-cycle-traits.cjs`。
- 85 项：`aibp-story-loot`、`aibp-loot-level`、`review-save-fixes` 与 `lan-save-regressions`。
- Windows 沙箱限制测试进程派生，因此以单个 Node 进程加载上述真实测试文件，181 项全部通过。
- Android 资源清单检查通过：4853 项映射、222 个普通探索入口和 1 个隐藏探索入口。Python 临时目录权限受限，使用 PowerShell 创建的工作区临时目录运行同一检查函数，其余断言保持原样。
- 内联 JavaScript 和特性模块语法检查通过，差异空白检查通过。
- 发布阶段自动审批已恢复，Chrome 实际页面检查通过：等级特性按钮、弹窗打开／关闭、桌面与 430px 手机尺寸显示、默认特性添加、特性取消／恢复以及指示物实时同步。测试使用发布工作树的页面代码与本机素材，全部战役接口为本地模拟，不写入真实存档。

旧打包目录中的取消资源副本及输出清单已在本机清理，已生成的 APK 和资料包未改写。本次正式发布由标签触发 GitHub Actions 创建新程序安装包与 Docker 镜像。

历史公告存在既有格式问题，本次只验证 v3.5.11 公告及现有发布脚本的资产规则，不改写历史公告。
