- 浏览器隔离预览：桌面和 375 像素手机宽度；新增、数量增减、旧文字显示在笔记开头。居中图标采用 CSS 横竖线，其中心固定在按钮 50%/50% 位置。预览使用合成数据。
- `python tools/test_android_campaign_import.py`：导入 102 项、简报 45 项、文件导出 10 项、持久化 60 项；附件存储、无效图片和账号隔离通过；随后执行的简报 JavaScript 契约 6 项与导出测试 18 项通过。
- `python tools/test_android_atopack_import.py`：117 项行为检查通过，包括安装资源与 APK 内导出图片的读取路径。
- Android 资源目录：4826 项映射；222 个普通探索入口和 1 个隐藏探索入口。资源覆盖 5 项、Docker 打包许可 1 项通过。
- Android versionCode 编码检查通过；预发布编码保留正式版升级顺序。
- 公开发布审计与差异空白检查已执行；暂存后的新增文件还会再次审计。

### 已知检查限制

`tools/test_release_assets.py` 的全目录公告格式检查在本次开始时已失败：`release-notes/` 内已有非版本命名的历史专题报告，且部分历史版本缺少该脚本要求的「更新/下载/验证」章节。本次公告使用正确的版本文件名和三个规定章节。历史公告未为使测试通过而改写；安装包资产规则与公告脚本接线会独立核对。

## 数据与使用边界

- 旧计数文本迁移保留原文与已有战役笔记，不将旧自由文本猜测转换为数量条目；仍可手动添加所需计数。
- 本次兼容修复能够保留现有存档中的文字，不能凭空恢复历史未落盘内容。个人恢复候选与备份排查结果保留在本地，不包含在公开报告中。
- Android 需要更新 APK 才能使用新增的 ZIP 与图片导出桥接接口；旧 APK 会收到明确的更新提示。
- 模拟器回归只操作项目指定的 `emulator-5554`，使用独立合成账号；不连接或修改实体手机。

## 发布方式

推送全部程序改动和 `v3.5.10-rc.1` 标签，触发 Android、Windows/macOS Portable、Docker 构建。版本带 `-rc.1`，Android 与 Portable 发布脚本会标记为 GitHub prerelease；Docker 只发布版本标签。发布正文来自 `release-notes/v3.5.10-rc.1.md`，完整报告随源码保存。
