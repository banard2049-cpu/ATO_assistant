# v3.5.10 变更与验证报告

日期：2026-10-10（Asia/Shanghai）。当前改动基线：`5768a1c`，即合并 `v3.5.10-rc.2` 后的 main；正式版相对上一正式版 `v3.5.9` 包含两个候选版的全部功能和修复。

## 变更范围

本次纳入工作区全部程序代码、资源路径清单、测试和相关文档改动。本地游戏素材、存档、备份、音频时长探针、预览及排查产物保留在本机，不进入程序发布。公告及本报告省略 C4/C5 的剧情、角色和具体战斗内容。

| 模块 | 变更与结果 |
| --- | --- |
| AIBP 卡图 | 网页与 Android 从实际图片清单确定可加载卡图，支持扩展名及正反面；移除可选卡图等待全部主图完成的旧限制，减少不存在图片的请求与连带等待 |
| AIBP 同步 | 删除自定义特性后的第二屏快照可正常读取；同步错误展示完整信息 |
| 战斗与结算 | 使用统一等级属性数据，保持手动标记及晋升进度；增加可撤销的致死补伤操作；按场景、结果和选择计算奖励，补齐结算验证及资源入账 |
| 记录表 | 资源小卡图复用，数量变化不再反复创建图片；修正 C2 船员区共同容量为未解锁 8、解锁后 9 |
| 素材库与 Android | 固定素材及补充路径清单保持一致；Android 导入和本机/局域网图片清单接口同步更新；排除 PSD 编辑源 |
| rc.1 内容 | 名称/数量计数列表、旧文字迁移、空循环数组兼容；Android 系统文件导出、Canvas 导出修复、同步存档写入与专用模拟器工具 |
| rc.2 内容 | C1 内蕴奥德赛知识初始 0 与导入/简报/回退联动；当前翻译版本显示；重置今日确认及取消保护 |

## 本次验证

- `tests/*.test.cjs` 与 `story/tests/*.test.cjs`：796 项通过。排除 1 项依赖本机私有素材的逐条双页面长时间穷举；其余私有素材检查按各测试自身可用条件执行。
- `tools/test-aibp-*.cjs`：8 组专项脚本通过，覆盖等级加成、战斗操作、特性、反面及图片读取。
- `tools/test_aibp_image_index.py`：2 项通过，检查仅公开已存在图片、导入后清单更新，不读取战役数据。
- Android Java：战役导入 109 项、简报 45 项、文件导出 10 项、持久化 60 项、资源包导入 123 项通过；附件持久化与账号隔离通过；简报 JavaScript 契约 6 项及文件导出 18 项通过。
- 素材库：`test_core`、`test_cryptic_resources`、`test_fan_pack`、`test_hostile_pack_safety`、`test_install_target_safety`、`test_bgm_resources`、`test_icon_resources` 共 93 项，92 项通过；1 项因缺少可选 APK 测试素材而跳过。使用项目已有 `.venv`，未改动用户全局 Python 环境。
- Android 目录：4854 项映射，222 个普通探索入口和 1 个隐藏探索入口；资源覆盖 5 项及版本号编码通过。
- 打包排除、Docker 挂载及打包许可检查通过；页面引用代码已纳入 Git。
- 本版公告与发布脚本的安装包资产规则通过；PHP 图片清单接口语法、公开发布审计及差异空白检查通过。

### 检查范围与现有限制

全量 `tools/test_release_assets.py` 仍报告既有历史公告文件的命名或缺少章节问题，涉及工作记录类公告及 `v3.5.7` 至 `v3.5.9` 的部分旧公告。本次仅对 `v3.5.10.md` 的公告格式与全部发布脚本、资产规则单独验证通过，未改写已发布的历史公告。

本次未重新执行真实 Android 模拟器全流程；候选版已有验证记录保留在 `v3.5.10-rc.1` 报告中。正式安装包和 Docker 镜像由标签触发的 GitHub Actions 构建，最终结果可在对应工作流查看。

原始大幅面卡图的尺寸与编码保持不变，传输及解码耗时仍受素材影响。此前本机频繁刷新出现的系统网络缓冲区错误，在退出占用大量连接的本地客户端后复测 50 次刷新未再失败；该结果不作为程序已修复操作系统连接耗尽问题的声明。
