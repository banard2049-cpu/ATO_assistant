## 下载

Windows、macOS、Android 请下载本页对应安装包。便携版请解压到新目录，并保留旧版本的 `data/` 和本地素材目录。

**请另外下载含勘误更新的官方故事书。故事书与私有资料包不包含在本次安装包和 Docker 镜像中。**

Docker 发布版本为 `2.0.3`，正式版构建完成后同步更新 `latest`：

```bash
docker compose pull
docker compose up -d
```

Android 沿用现有签名策略；未配置发布签名密钥时使用 Debug 签名。升级前请保留可恢复的数据，卸载会删除应用内账号、存档和素材。
