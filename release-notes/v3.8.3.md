# ATO Assistant 3.8.3

修正地图标记与主控台同步、科技自动化条件判定，以及 AIBP 资源标注和结算数据。

## 更新

- 地图和主控台移动、翻面后同步更新当前标签、派系、最新探索状态、侦察船及笔记，科技提醒随新位置更新。
- 补齐主控台移动时的最后到访地点标记；最后城市、绿洲和白银遗迹标记保持唯一。修复 AG 标记移入宿敌所在板块时漏触发战斗。
- 地图请求期间切换档案、循环或登录会话时，停止把旧请求结果写入新上下文。
- 修正谈判能力误用其他循环地图快照，以及待确认打捞奖励随地图移动错误切换派系的问题。
- 对照普通资源卡卡面，修正 20 张 BP 卡的资源种类或数量，并验证掉落计算和记录表写入。
- 资源标注工具保存和导入导出时保留人工审核状态，防止预填草稿被误记为已核对；过滤其他循环的资源，并明确提示不支持的导入格式。

本次修复影响后续操作与结算，不追溯调整已有存档的资源余额。

## 下载

在本 Release 的 Assets 中选择 Android APK 或 Windows／macOS 便携包。Docker 使用 `ghcr.io/banard2049-cpu/ato_assistant:3.8.3`。

程序更新不包含个人存档及游戏图片、故事和音频；已有战役存档继续兼容。

## 验证

1,455 项 JavaScript 回归测试通过。地图返回主控台后的自动捕获、刷新不重复结算和手机布局通过浏览器检查；资源标注 API、科技分类与发布排除规则通过对应检查。新增回归已加入持续集成。

正式安装包与 Docker 镜像由本标签的 GitHub Actions 构建发布。
