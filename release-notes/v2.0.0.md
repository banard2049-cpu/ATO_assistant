### 官方翻译（术语）

- **勘察步骤「定数框」全中文**：分支总表的表内内容、每张分支卡的冒险名与标签徽章、R&R 冒险名，
  C1–C3 全部按故事书官方版的对应标题替换（例如 `Fated Conundrum` → 宿命的迷境、`Bitter Seeds` →
  苦涩的种子、`Catch of the Day` → 今日渔获），不再出现英文。
- **战斗地形用官方地形卡的卡面名**：`Maze Outcrop` → 迷阵露头层、`Giant Shell` → 巨型贝壳、
  `Krypteia Outpost` → 克里普提前哨、`Spot of Nothingness` → 虚无场地……共 11 张，分区一并写成
  「（内圈3）」「（外圈3）」。
- **主线故事 / 特殊事件定数框**：落败条目按官方正文写成「船体耗尽」「船员耗尽」「阿尔戈号命运耗尽」；
  特殊事件按官方标题写成 粗暴觉醒 / 深不可知的永世 / 残忍的永世 / 无尽的永世 / 明日边缘 等。
- **英雄记录表**：回忆卡上的词条徽章（`deed` / `voyage` …）在官方翻译下显示中文（事迹 / 航程 …）。
- **修掉「短条目连锁改写长条目」的老毛病**：术语原来是按长度倒序逐条替换，短条目会把长条目刚写出来的
  官方名再改一遍。现在改成只对原文取一次最长命中，一次性修好 10 处，例如：

  | 文案 | 修复前 | 修复后 |
  | --- | --- | --- |
  | Market Forces | 市场狂怒 | 市场力量 |
  | Cyclops Trap | 无眼巨人陷阱 | 独眼巨人陷阱 |
  | 阿尔戈号命运耗尽 | 阿尔戈命运耗尽 | 阿尔戈号命运耗尽 |
  | Cycle III 航行时间表 | 故事集纪 III 航行时间线 | 循环纪 III 航行时间线 |
  | 赫尔墨斯弩炮 | 赫尔墨斯弩炮枪枪 | 赫尔墨斯弩炮枪 |

### 故事模块：深链短号跳转

主控台与地图提醒用「箱号 / 编号」跳转故事书（`12`、`1-2`、`α`、`Ω`…），但多数循环的条目 id 是
「编号 + slug」（c1 内蕴奥德赛 `12-the-argonites`、c3 冒险中枢 `1-2-turf-laws`，c1 的 α 箱子更是
只写在标题里）。精确 id 查不到时现在会按 id 前缀、再按标题前缀在**指定章节内**匹配，缺了这层会静默
落回该章第一条（表现就是「按钮不跟着进度跳」）。同时给回忆突破加了章节键别名，`c2` 的单数
`mnemos-breakthrough` 和主控台写的复数都能落到当前故事书自己那一章。

### AIBP 战斗工具：Token 名单

「新增 Token 堆」弹窗改成只按页内写死的名单渲染，不再加载 `token_manifest.js`，也彻底去掉了
「猜文件名」（`001.png` / `TOKEN_001.png`…）和目录列举回退——静态部署下那两条路径只会得到 404。
名单里有、本机缺图时不再隐藏整项，而是把图位换成文件名占位，便于看出缺的是哪张。

### 资料包打包（rc.1 起）

- 新增 `tools/build_fan_pack.py`（民间版）与 `tools/build_official_pack.py`（官方版），共用同一份
  打包引擎，素材真源改为工程目录（实测素材库曾缺 6 张图、59 张是旧版本）。
- 导出被打断不再留下打不开的半成品包：先写 `.partial` → 刷盘 → 校验（成员齐全、大小一致、哈希抽样或
  全量比对）→ 原子改名，最终文件名上只可能出现完整、已校验的包。
- 详见 `2.0.0-rc.1` 的更新公告与 [.atopack 打包说明](asset-studio/ATOPACK-PACKING.md)。

## 下载

Windows、macOS、Android 请下载下方对应安装包。便携版请解压到新目录，并保留旧版本的 `data/` 和本地素材
目录（图片、故事数据、`assets/bgm/` 音频都不在安装包里，需要自备）。

Docker 镜像同步发布 `2.0.0` 标签，并把 `latest` 移到本版：

```bash
docker compose pull
docker compose up -d
```

Android 沿用现有签名策略：未配置发布签名密钥时提供 Debug 签名 APK。不同构建的签名可能不一致，无法保证
覆盖升级；卸载会删除应用内账号、存档和素材，升级前请确认数据可恢复。

**安卓导入要求**：APK 需为 **1.4.1 或更新**（内置资源名单 4298 个目标；1.4.0 不认「逆行动量」，更早的
版本不认 C2 探索卡 13642，1.3.2 以前的 APK 不支持格式版本 3）。导入时先把整包拷进应用缓存、再把每个
文件落到内部存储，**需要约 2× 包大小的可用空间**（官方版 4.18 GiB → 约 8.4 GiB；民间版 2.76 GiB →
约 5.5 GiB）。

资料包为本地私有产物，不进仓库、不进安装包；仓库的 `.gitignore` 已排除 `*.atopack` 与
`official-assets/`。
