# ATO Assistant 3.6.0

本次加入英文界面，并重新整理主控台的语言选择。公告省略后续循环的剧情、角色与具体战斗内容。

## 更新

- 主控台的语言按钮只显示当前语言，点击后从弹出菜单里选民间翻译、官方中文或 English，不再并排占三个按钮的位置。选择仍然同步到其他模块，并在刷新后保留。
- 英文界面使用原版 App、TTS 或数据里已有的英文原名：Boss、定数框标题、科技与装备名称、故事条目标题等沿用原文；工具自身的按钮、状态提示和对话框另行提供英文文案。
- 英文规则与故事正文需要本地原文数据。没有原文的内容显示缺失提示或段落引用，个人笔记、自定义名称和卡牌图片保留原来的内容。
- 新增 `tools/build-english-terms.py`，可从本地原文数据重建英文术语表。
- README 增加英文版 [README.en.md](README.en.md)，中英两版顶部可互相切换。英文版说明里同时写明英文界面依赖本地原文数据。
