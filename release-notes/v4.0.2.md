# ATO Assistant 4.0.2

## 更新

- AIBP 的 C1–3 Boss 大卡背面切换到民间翻译时，会整行重排有术语变化的文字。重绘正文按卡面统一字号，保留字形比例和行内图标。补齐「生死关头」到「硬币」等术语，包括尼采超人的「硬币抽取」。
- 补齐部分额外卡牌的中文卡名和规则译文。特性区现在也会显示 O／X 级状态卡，可通过特性选择控制显示。
- 同步地图矢量构建清单，并补充 Windows 双击启动时发布者验证提示的维护说明。

## 下载

Android、Windows 和 macOS 安装包请见发布页附件。Docker 镜像为 `ghcr.io/banard2049-cpu/ato_assistant:4.0.2`。

## 验证

在 Chrome 中逐张渲染了 10 张有术语覆盖的卡背，并检查页面与放大图的语言切换。迷宫机牛的伤害图标和句号通过了原图像素比对。
