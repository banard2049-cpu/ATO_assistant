# ATO Assistant 3.7.3

本次正式版包含 3.7.3-rc.1 的全部修正，并补上背景音乐加载与 Android 局域网端口修复。

## 更新

- 修复 BGM 首次加载失败后一直保留“文件缺失”记录的问题。音频在页面打开后挂入或补齐时，关闭再开启音乐即可重新检查，不必刷新整个页面；迟到的旧探测不会把正在播放的音频再次标为缺失。
- 兼容旧的自定义 BGM 曲目清单：未配置 `packDir` 时，默认也会查找 Docker 的 `assets/bgm/media/` 音频目录；显式配置空字符串仍可关闭回退。
- Android 局域网服务优先使用固定端口 `37403`；端口被占用时自动使用空闲端口，关闭服务后释放端口。
- 纳入 3.7.3-rc.1：记录表泰坦死亡每次只减少一个，死亡累计增加 1，数量归零时移除该行。
- 纳入 3.7.3-rc.1：残废与恢复每次只改变一个泰坦的状态，多个泰坦拆分数量，同名残废泰坦自动合并。
- 纳入 3.7.3-rc.1：修正 C3 特殊事件定数框文字溢出，事件名称支持换行，窄列下多勾选框与文字分行显示。
- 提交 App 与 Tabletop Simulator 桌面补全交接指南；该指南记录后续方案，本版尚未新增 TTS 自动部署功能。

## 升级

- 本次仅更新程序，继续使用已有存档和游戏资源，无需更换资源包。
- Windows/macOS 可使用程序内一键更新；Android 安装新版 APK；Docker 拉取 `3.7.3` 或 `latest` 后重建容器。
- Docker 用户仍需保留 BGM 的两条挂载：`./app/assets/bgm/audio:/app/assets/bgm/audio:ro`、`./app/assets/bgm:/app/assets/bgm/media:ro`。更新镜像不会自动修改宿主机旧 Compose；缺少挂载时需同步配置并重建容器。
- 更新后刷新已打开的页面，以加载新版播放器。

## 下载

- Android：`ATO-Assistant-3.7.3.apk`，使用固定发布密钥构建。
- Windows：`ATO-Assistant-Portable-3.7.3-windows-x64.zip`。
- macOS：`ATO-Assistant-Portable-3.7.3-macos-arm64.zip`、`ATO-Assistant-Portable-3.7.3-macos-x64.zip`。
- Docker：`ghcr.io/banard2049-cpu/ato_assistant:3.7.3`，正式版同步更新 `latest`。

公开程序包不附带游戏音频、卡图、战役存档或 atopack，继续使用已安装的游戏资源。

## 验证

- BGM 播放器 34 项、流程联动 6 项测试通过，覆盖旧清单、迟到挂入的 MP3、迟到的 404 和重复开启不重播。
- Android 固定端口、占用回退、端口释放以及 versionCode 升级检查通过；正式版可覆盖安装在 3.7.3-rc.1 之上。
- Docker 挂载与安装器回归检查通过；Android、Windows/macOS Portable 和 Docker 镜像由 GitHub Actions 构建。
