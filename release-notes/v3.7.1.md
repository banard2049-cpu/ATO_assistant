# ATO Assistant 3.7.1 · 重大更新

**建议所有用户更新至 3.7.1。** 本次修正影响探索卡结算、进展与灾祸放置、地图派系判断和始徒面板操作。正在进行战役的用户也建议更新程序，并刷新已打开的页面。

## 更新

### 探索卡与故事卡规则修正

- 复核五个循环的 223 张探索卡，修正 27 张卡的图标、数值条件、派系条件和文字转录。重点纠正船体被认成泰坦、陌生人被认成祭司，以及进展、灾祸、命运和猜忌之间的误认。
- 连续操作合并为一条完整提醒；同一条件下的掷骰和奖励一起提示。替代效果只显示对应分支，避免同时提示互相替代的英雄效果。
- 正确区分宿敌标记与泰坦，修正部分战斗升级门槛及指定派系的同盟条件。
- 补齐条件洗回、暂时移出与永久移出的分支。破坏卡按条件返回破坏卡组或暂时移出；暂时移出的卡在下次定时战斗结束后放回。结算保存已选分支，撤销时恢复原去向。
- 复核 80 个故事、灾祸与内蕴奥德赛卡面，按当前面显示进展／灾祸放置许可及数量上限；多段上限一并展示。**上限仅用于提醒，达到或超过上限仍可继续放置。** 内蕴奥德赛提醒上限为 1，并显示当前知识，恢复手动调整进展。
- 主控制台提醒可直接选择故事卡、符合规则的灾祸卡或内蕴奥德赛，显示已放数量与上限。灾祸卡只有允许放置进展时才出现进展栏和对应提醒。
- 探索卡获得的进展／灾祸移至故事／灾祸模块提醒，保留卡牌来源、条件、数量及快捷操作；结束探索、继续抽牌或重新读取存档后，未完成的放置待办仍保留。
- 修正特定故事卡“获得进展时改为移除”的操作，使用减号按钮，并确认卡面要求的最后访问城市条件。正常手动计数仍可调整。
- 提醒栏改为紧凑的方形布局，去除多余说明行和探索提醒中的大型“已手动放置”按钮。

### 地图角标与双面标签修正

- 逐面复核 511 个地图面，修正 47 面的进展／灾祸或派系角标，改善地图与主控制台的放置提醒、外交条件判断。
- 修复双面地图标签在编辑器及服务器保存时被合并覆盖的问题，基础记录与 A／B 面记录独立保留；反复保存和并发冲突处理继续保留各面的数据。

### 始徒面板与第二屏

- 修正相关始徒大卡上的轨道红圈、状态圈、指示物和损伤锁定位，适配官方中文卡面的印刷坐标差异。
- 浮层按实际卡图显示区域定位，缩放、旋转及第二屏留白后仍保持贴合；切换预览与原图时保留选中状态。

## 升级与旧存档

- 更新前建议导出一次战役存档；更新程序后继续使用已有战役和合法资源，并刷新所有已打开的页面。
- 旧版已结算的错误图标或遗漏收益会提示更正，可先撤销旧结算再按新规则处理。旧条件登记的战斗升级也保留核对与撤销入口；不会直接改写历史计数或重复发放收益。
- 快捷放置仍由玩家选择位置。涉及实际地图、装备、英雄、剧情或战斗操作的剩余效果继续保留手动提醒与确认。

- Android：`ATO-Assistant-3.7.1.apk`，使用固定发布密钥构建。
- Windows：`ATO-Assistant-Portable-3.7.1-windows-x64.zip`。
- macOS：`ATO-Assistant-Portable-3.7.1-macos-arm64.zip`、`ATO-Assistant-Portable-3.7.1-macos-x64.zip`。
- Docker：`ghcr.io/banard2049-cpu/ato_assistant:3.7.1`；正式版同步更新 `latest`。

安装包和镜像由 GitHub Actions 构建。公开程序包不附带游戏卡图、规则书、战役存档或 atopack；继续使用已安装的合法资源。
