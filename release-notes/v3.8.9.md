# ATO Assistant 3.8.9

> **一定、一定、一定要重新下载最新的 ATOPACK，并重新导入！**
>
> 本版包含**重大地图错误修正**：重新核对了 511 个分层地图图面，补全 21 张蒙版中遗漏的 40 处地图信息。修正只存在于重新打包的 ATOPACK 里；**只更新程序不会修正本机地图素材，旧资料包会继续缺标或显示错误信息**。请以 2026-10-20 重新导出的民间版／官方版分层地图 ATOPACK 为准，按原渠道重新下载并覆盖导入。

## 更新

### 地图

- 补全 40 处地图标记：C1 的 α/β 圆标、密码牌与 KNOSSOS 地名牌，C3 的 α/β 圆标，C4 的 α/β 圆标与邻接字母框，C5 的密码牌与邻接标牌。底图和其他图层保持不变。
- 未探索区域改为按“实际可通行的出口”显示相邻板块：贴着但中间是墙的板块不再被误显示；已揭示、侦察船／引擎／黑夜宁芙揭示、特殊航路与云端追逐按各自规则处理。
- 进入板块只记为“已揭示”，进入下一天才结算为“已探索”；科技提醒、简报和地图快照使用翻开日期，避免当天刚翻开的板块被误判为早已探索。
- 新增“显示网格”复选框，默认关闭，开启后按当前循环的板块行列显示网格线，设置会保存并同步到第二屏。
- 修正 C3 凝固时光提醒、泰坦 X 追踪与捕获、板块搜索、图标标记清除、C5 揭示面继承与水下／水上揭示等地图流程。
- “保存并返回”不再整页重载主控台：先聚焦已打开的主控台，再原地同步地图与面板。

### 科技与交易

- 新增交易规划器：资源用图标选择，自动寻找库存与额度内比例最优的兑换路径，必要时经过中间资源；逐笔预览资源前后数量，可撤销上一步或整条路径，确认后一次性保存资源、命运与冷却。
- 结构科技按一次性、豁免、谈判、主动、参考、永久、被动等类型细分；科技详情、谈判列表和交易规划共用同一套折叠行与两栏宽度规则。
- 谈判列表改用与“科技航行能力”一致的展开卡布局，代价与效果分开显示；资源支付占满整行，展开行横跨两栏。
- 修正科技缓存、到期提醒、修复目标、支付校验及旧谈判编辑器的兼容问题。

### 主控台与流程

- 在“今日流程”顶部新增扎根提醒，与科技到期提醒同列；已扎根后显示确认状态且不可重复执行。
- 追踪结算新增“自动／手动”模式，并保留手动模式的追踪标记数量与明细。
- 探索结算改为一次提交：自动效果先预览、再随追踪事件合并写入，失败不会留下未提交的本地结算结果；结算期间先绘制结果，避免长时间无反馈。
- 记录表新增“当前阿尔戈号知识”等卡片轨道信息，日期轴、简报回放、英雄回忆与备份继续兼容旧存档。
- 统一模块返回导航：已打开的主控台标签页优先复用并原地同步，不再重复开页或整页刷新。

### 记录、故事书与其他

- 密语记录保存原始字形与保存时已记下的读法；当时未知的字符在之后记下对应时自动补全显示，空格、标点和分词保持不变。
- 记录表图标缓存版本更新，移除泰坦列表多余分隔线。
- 修正 AIBP 卡图、图标提取、记录附件、故事书模块与若干界面细节。
- 存档备份改为硬链接／重命名轮转，减少每次保存复制整份战役文件的磁盘写入。

## 下载与升级

在本 Release 的 Assets 中选择 Android APK 或 Windows／macOS 便携包。Docker 使用 `ghcr.io/banard2049-cpu/ato_assistant:3.8.9`，正式版同时更新 `latest`。

**再次提醒：程序更新后必须重新下载并导入最新 ATOPACK。** 本次地图修正不在程序包里；不换资料包，地图上仍会缺标或显示错误信息。

程序包不包含个人存档及游戏图片、故事或音频资源；已有战役存档继续兼容。
