## 更新

本版本整合记录表、故事、主控台、地图、英雄与素材工具的多项体验改进：

- 为五个 Cycle 加入统一标题图标，并在主控台、地图、记录表、英雄和故事界面联动显示；故事页同时按当前 Cycle 使用对应主题配色与布局。
- 第二屏故事显示现在可以在官方扫描图与官方正文之间切换，便于按本地资料情况选择展示方式。
- BGM 刷新页面后会恢复启用状态和手动锁定的阶段，不再意外回到默认播放流程；同时调整 Story TTS 快捷配置。
- Asset Studio 和打包工具支持从本地 `official-assets/` 读取官中图片覆盖，并将匹配素材写入资料包。该目录中的私有图片不会提交到源码，也不会进入公开安装包。
- 记录表的关系轨道在选择关系后会尽量把当前值滚动到可视区域中央，靠近两端时停在轨道边界；同时修正关系倒三角标记显示。
- 修正超时光先知的 AI X 卡背显示、科技树中文条件文字与复选框遮罩，以及 Cycle IV / V 的 BP 资源顺序。

## 下载

Windows、macOS、Android 请下载下方对应安装包。便携版请解压到新目录，并保留旧版本的 `data/` 和本地素材目录。

Docker 的 `latest` 标签同步更新至 1.3.5。如果此前在 `.env` 中固定了版本，请改为 `ATO_VERSION=1.3.5`，然后运行：

```bash
docker compose pull
docker compose up -d
```

Android 沿用现有签名策略：未配置发布签名密钥时提供 Debug 签名 APK。不同构建的签名可能不一致，无法保证覆盖升级；卸载会删除应用内账号、存档和素材，升级前请确认数据可恢复。

游戏图片、完整故事正文、官中覆盖图片和 `.atopack` 资源包仍由本地资料提供，不包含在公开安装包中。
