# ATO Assistant 3.8.1

地图改为高清底图与可隐藏的图标蒙版，统一更新地图显示、图标标签和资源包导入。同步修正卡牌扫描边缘显示，并补充地图资源结算提醒。

## 更新

### 高清地图与卡背

- 511 个地图面使用 1024 像素底图与独立透明蒙版。关闭地图标志可查看干净底图，本图、邻接及航路标志一起切换，第二屏同步显示。
- C1–C3 卡背共用 3 张底图，数字与说明单独叠加；C4 卡背保留原样。缺少新版资源时回退旧整图，兼容原地图编号、翻面状态和战役存档。
- C5 使用官方下潜按钮，并加入重新处理的船形上浮按钮，调整箭头、船形比例与留白。
- 简报地图、GIF／PDF 导出及标签编辑器统一使用分层地图，移除对已归档扫描图的依赖。

### 地图图标与规则

- 核对全部循环的地图图标，包含 C1 替代板块与 C5 双面，修正中枢、休整、城市、野生泰坦及循环特殊地点等标签。
- 四个方向的出口图标记录为邻接板块提示，包含方向与目标编号，避免当成本地图属性；内部航路单独保留。
- 野生泰坦标签用于已有捕获与自动获得判定，保留重复领取和多页面并发保护。
- C3 新探索凝固时光板块时，按时间对策科技自动登记资源：容量 3，高级时间对策容量 5。侦察、重访和旧存档已探索地点不补领，已满或未解锁时也记录机会已处理。
- C2 斯巴达要塞在移动步骤提醒探索损失，仍由玩家选择并手动结算；C4 埃米尔云船作为唯一标记移动，不自动揭示或探索目标。

### 卡牌显示

- 探索、战斗、科技、记录与第二屏等页面统一按实际图像区域处理圆角，适应缩放、横竖版切换与留白。
- 仅对匹配已测量民间卡图的版本去除细扫描边线，保留卡面印刷边框，原图片文件保持不变。
- 调整主控台卡面容器，使高度跟随图片比例并限制竖版卡高度。

### 资源包与发布工具

- `.atopack` 增加可选 `mapFiles` 段，分发 1302 张地图底图与蒙版，不重复打包已被替代的 781 张旧扫描图。
- Android、Asset Studio、完整包／更新包打包器与 Docker 目录准备同步适配。支持图层完整性与哈希校验、冲突选择、安装和再次导出，旧整图包继续兼容。
- Q85 豁免名单覆盖整个 `map/`，地图底图、蒙版、卡背、切换按钮及地图标记按原字节保存；其他符合收益条件的图片使用 Q85，不缩放分辨率。
- 本次 Q85 民间资源包约 2.02 GB，官方资源包约 3.25 GB。资源包仍由本地素材通道分发，不随公开程序安装包上传。
- 补充本机备份与任务续跑文件的发布排除规则，并将新增地图与卡牌回归测试接入持续集成。

## 下载

在本 Release 的 Assets 中选择 Android APK 或 Windows／macOS 便携包。Docker 使用 `ghcr.io/banard2049-cpu/ato_assistant:3.8.1`。

使用新分层资源包前，请先更新到本版程序。旧 APK 会忽略新增图层字段，无法显示仅由新图层保存的地图。程序更新不包含个人存档及游戏图片、故事和音频；旧资源包、地图编号和存档引用继续兼容。

## 验证

地图图层、图标作用范围、野生泰坦捕获、凝固时光结算、云船、卡牌显示与主控台组合回归 88 项通过。Android 导入器 180 项行为检查及资源名单校验通过。

两份 Q85 包通过全量哈希与 ZIP CRC 检查；包内 1413 个地图文件逐一与未重编码版对比，字节完全一致，包括最终上浮按钮。正式安装包与 Docker 镜像由本标签的 GitHub Actions 构建发布。
