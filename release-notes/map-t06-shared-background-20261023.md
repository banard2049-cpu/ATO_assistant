# T06 共用牌背底图

C1、C2、C3、C5 改为共用 `map/images/card-backs/c1-base.png`。底图来自用户提供的 TTS 创意工坊 1957681721 中 T06 牌背（对象 f98850）。用内置 ImageGen 去除顶部 T06 编号、牛头徽章及其边框，补齐遮挡处的背景。生成图为 1254 × 1254 PNG；原图为 827 × 827，生成尺寸不代表原始素材分辨率提升。

配色：C1 棕金原色，C2 红色，C3 蓝灰色，C5 蓝黑色。C2/C3 使用注册表 `baseFilters`，C5 沿用蓝黑滤镜。滤镜只作用于底图，编号与派系蒙版维持原色。C5 揭示面及上浮/下潜标记未修改；特殊说明牌背仍使用完整原图，C4 保持原方案。

根据用户反馈，第二版提高 C2/C3 的饱和度与亮度：C2 使用 `saturate(1.65) brightness(1.1)`，C3 使用 `saturate(3.4) brightness(1.25)`，呈现更鲜明的红色和蓝色。预览已更新，浏览器检查通过。

第三版对照 TTS 模组 3458296558 的 C3 001 原始牌背（FaceURL 图集、CardID 9545），卷轴区域平均色相约 239.6°，确认为蓝紫色。C3 的 `hue-rotate` 从 175° 校正为 201°，保留第二版的饱和度和亮度。原图摘取保存在预览目录的 `tts-c3-001-reference.png`。

第四版按用户明确的暗紫色要求，将 C3 调整为 `hue-rotate(222deg) brightness(0.82)`，饱和度维持 3.4；颜色更偏紫，亮度降低。滤镜仅影响底图。
