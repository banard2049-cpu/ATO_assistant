# ATO Assistant 2.0.5-rc.1 预发布报告

本次预发布基于 2.0.4，加入 Cycle V 的**一条新追踪轨**、**法洛斯之梦标题解密**，并新增一个 Cycle V 地图标记与相应的素材包清单项（**这两处的名称与关键细节涉及剧透，公告里都以折叠块遮住，不点开看不到**）。

## 更新

## Cycle V 追踪轨

- 主控制台与地图模块都新增一条 1–7 格的追踪轨，用来接管该循环原本的宿敌移动：「生成宿敌」改为生成追踪目标并把指示物放到起始格，追击按钮在该循环显示为「追踪推进 1 格」，另加「追踪减缓 1 格」（本次探索阶段没有激活探索指示物时使用）。
- 指示物经过特定格数时，航行模型会随机落在阿尔戈号相邻的板块上（优先未探索的相邻板块）；地图模块在无法确定落点时会提示手动放置。
- 指示物走到末端、与阿尔戈号相遇、或对应战斗结束时，追踪轨清空；该循环的宿敌与航行模型因此不会同时出现在地图与追踪轨上。
- 旧存档兼容：该循环里已经放过宿敌、但没有追踪位置的存档会按起始格读入，不会丢进度。
- 这条追踪轨对应的名称与触发格数属于剧透，放在下面的折叠块里，**不点开看不到**。

<details>
<summary>⚠️ 含剧透：这条追踪轨的名称与触发格数（点击展开）</summary>

这条追踪轨对应 Cycle V 的 **泰坦 X（Titan X）**：生成时把指示物放在 **7**；经过 **6** 与 **3** 时放置泰坦 X 航行模型；走到 **1**、与阿尔戈号相遇或战斗结束时清空。旧存档按 **7** 迁移。

## Cycle V 板块 A/B 面继承

- 阿尔戈号移动到尚未探索的板块（方向移动、特殊连接、地图命令都算）时，新板块沿用**出发板块的面（A/B）**，主控制台与地图模块规则一致，不再出现两边翻面不同步。
- 地图摘要与主控制台状态会显示当前板块与最近揭示板块的面别。

## 地图标记

- 「唯一标记」不再只针对侦察船：标记池里声明为唯一的标记，放到别的板块时会自动移除原位置；读档时同一标记的重复记录也会收敛成一个。Cycle V 的 **Black Beak**、**Nemesis** 与本版新增的那个标记都按此规则，只能放在一个板块上。
- 宿敌所在的板块在板块列表与「仅看已探索」过滤下始终可见，不会因为过滤而找不到宿敌。
- 本版新增的 Cycle V 标记，名称与素材出处属于剧透，放在下面的折叠块里，**不点开看不到**。

<details>
<summary>⚠️ 含剧透：新增标记的名称与素材（点击展开）</summary>

新增 Cycle V **战后塞壬（Ae-Siren）** 标记，素材取自该始徒的卡背插画（旋转到正向后裁成 512×512），已加入 Cycle V 标记池。

</details>

## 法洛斯之梦标题解密

- 新增 `story/assets/pharos-codes.js` 与对照表页面 `story/pharos-codes.html`。
- 阅读器标题旁新增「标题解密」按钮：法洛斯之梦里以数字串结尾的标题按 A=1、B=2 … Z=26 解开，民间版给出英文，官方版给出中文（拼音，不含声调）；点一次解密后翻页不会自动还原，再点一次也不会重复替换。
- 故事搜索同时匹配解密后的标题，搜中文名也能找到对应段落。

## 主控制台

- 冒险枢纽的回忆勾选框改为**先保存状态并重绘，再**触发英雄进度提示与记录同步，避免刚勾上的格子被随后刷新的面板还原。

## 素材包

- 资源清单新增 1 个 Cycle V 标记（名称见上方折叠块），清单由 **4298 个面**增加到 **4299 个**。
- 官方版、民间版增量打包补齐了底包的源文件指纹（源文件大小与修改时间、图片编码口径），本次重建：粉丝版 **4 秒**（复用 4299/4299 成员）、官方版 **43 秒**（复用 6494/6500 成员），比全量重编码快两个数量级；两份产物都用 `tools/check_pack.py` 复核为「包是完整的」。

## ⚠️ 安卓用户请安装本版 APK

- 本次资源清单新增一项（就是上文折叠块里那个 Cycle V 标记，这里同样不点名）。安卓端导入资料包时会拿 **APK 内置名单**逐项核对，**旧版 APK 遇到这一项会整包拒绝导入**，提示「资源不在当前 Asset Studio 名单中」。
- 所以：**要导入包含这个新标记的资料包，安卓端必须先安装本次发布的 2.0.5-rc.1 APK**（内置名单已更新到 4299 项）。装好后再导入资料包即可，不需要卸载重装资料。
- 不导入新资料包、只使用现有素材的安卓用户不受影响，可以继续用旧版本；桌面便携版与 Docker 版也不受这条限制。
- 资料包（`.atopack`）仍是本地私有产物，不在本页附件里，需要另行分发；新标记只有在拿到含它的资料包后才会出现在地图上。

## 下载与升级

Windows、macOS 和 Android 安装包由 GitHub Actions 构建，实际产物以本页附件为准。便携版建议解压到新目录，保留旧版 `data/` 和本地素材。

Docker 镜像版本为 `2.0.5-rc.1`，提供 `linux/amd64` 和 `linux/arm/v7`。这是预发布版，不更新正式版 `latest`。需要试用时，在 Docker 安装目录的 `.env` 中设置 `ATO_VERSION=2.0.5-rc.1`，再执行：

```bash
docker compose pull
docker compose up -d
```

Android 沿用现有签名策略；未配置发布签名密钥时使用 Debug 签名。卸载会删除应用内账号、存档和素材，请在需要卸载重装前保留可恢复的数据。

本次公开发布仅包含程序源码及程序安装包，不上传本地游戏素材、故事书、音乐、资料包或用户存档。2.0.3 提醒的官方故事书勘误仍需从原获取渠道另行更新。
