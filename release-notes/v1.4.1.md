## 更新

本版本补录 C2 探索卡「招募活动」，并修掉素材库两个会让人卡住的问题：老素材库打不开、导出慢一个数量级。

### 探索卡与固定清单

- 补录 **C2 探索卡「招募活动 / RECRUITMENT DRIVE」**（app 卡号 `13642`，实体卡号 BB1241）：主控台 C2 牌组由 42 张变为 43 张，抽卡、牌库选择与结算数据都认这张。
  - 标签按卡面写定：**永久移出**（卡底印「从牌库中永久移除。」）、**连抽**（会移出的卡都要补抽，与全库 67 张移出卡的规则一致）。
  - 卡面规则：获得 1 船员；徽章「结盟」下失去 1 阿尔戈号命运。
  - 卡图由使用者自备（`assets/exploration-cards/c2/13642.png`），素材库会把它列进待拍摄 / 待导入项。
- 固定清单规模 2775 → **2776** 条、4297 → **4298** 个目标。
- **补条目必须递增清单版本号**：素材库只在 `catalog_version` 变化时才重写清单，否则老库永远看不到新条目（既不会提示补图，也打不进资料包）。本次两批新条目都补了版本后缀，并加了回归测试锁住这个门控。
- 探索卡转录里的图标改用正式资源名（19 张卡）：`✕ = 船员 Crew`、`黑三角带白钩 = 阿尔戈号命运 Argo Fate`、`骷髅 = 灾祸 Doom Token`、`苍白徽记 = 进展 Progress Token`。

### 修复

- **老素材库无法启动**：`pending_files` 上的索引建在「补 `import_seq` 列」之前，旧库一启动就报 `no such column: import_seq`，素材库直接打不开。现在索引改到加列迁移之后建立，旧库能正常打开并自动迁移（新增回归测试）。
- **资料包导出慢一个数量级**：官中图片覆盖查找每次都重扫 1300+ 张官方图并重建四张索引表（实测单次 426 ms），4000+ 张素材就是几十分钟纯开销。索引改为带缓存（2 秒自动失效，另提供显式清理），实测单张 426 ms → **3 ms**，整包导出从约一小时降到**六分钟**。

## 下载

Windows、macOS、Android 请下载下方对应安装包。便携版请解压到新目录，并保留旧版本的 `data/` 和本地素材目录。

Docker 的 `latest` 标签同步更新至 1.4.1。如果此前在 `.env` 中固定了版本，请改为 `ATO_VERSION=1.4.1`，然后运行：

```bash
docker compose pull
docker compose up -d
```

Android 沿用现有签名策略：未配置发布签名密钥时提供 Debug 签名 APK。不同构建的签名可能不一致，无法保证覆盖升级；卸载会删除应用内账号、存档和素材，升级前请确认数据可恢复。

**Android 需要更新到 1.4.1** 才能导入含 C2 新卡「招募活动」的资料包：1.4.0 及更早的 APK 内置名单里没有 `13642` 这条，导入会被拒绝（本版内置名单为 4298 个目标）。

游戏图片、完整故事正文、官中覆盖图片和 `.atopack` 资源包仍由本地资料提供，不包含在公开安装包中。「招募活动」与「逆行动量」的卡图同样需要自备，位置分别是 `assets/exploration-cards/c2/13642.png` 与 `aibp/ps/other/trait/COMMON_TR_002.jpg`。
