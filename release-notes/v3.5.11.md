# ATO Assistant 3.5.11

本次修正 Boss 等级特性的显示与指示物同步。公告省略后续循环的剧情、角色与具体战斗内容。

## 更新

- 核查 21 个 Boss、182 个已记录等级，补齐特性的添加、移除和替换规则。已被当前等级取消的特性不会因旧存档的显式选择再次显示。
- 特性自带的属性指示物随特性启用、取消或等级变化自动同步，只增减该特性的贡献，保留手动数量、位置与其他等级加成。
- AI 区新增“查看等级特性”按钮。点击弹窗查看当前生效、移除／禁用的特性及需要手动处理的效果；原卡牌展示区不再常驻这段说明。
- 补齐部分内置特性的选择与恢复操作；条件状态和条件奖励按各自触发规则处理，并提供必要提醒。
- 移除一张已取消的旧资源登记，统一资料包打包与 Android 导入清单，并兼容旧卡图缓存与存档。

## 下载

- Android：`ATO-Assistant-3.5.11.apk`。
- Windows：`ATO-Assistant-Portable-3.5.11-windows-x64.zip`。
- macOS：`ATO-Assistant-Portable-3.5.11-macos-arm64.zip` 与 `ATO-Assistant-Portable-3.5.11-macos-x64.zip`。
- Docker：`ghcr.io/banard2049-cpu/ato_assistant:3.5.11`；正式版同时更新 `latest`。

程序包不包含游戏素材。现有资料包与存档可继续使用。

## 验证

- 特性、等级、卡图、第二屏与选择操作相关回归 96 项通过。
- 战利品、重复入账防护、账号／档案／循环锁定及记录表冲突重试相关回归 85 项通过。
- Android 资源清单 4853 项映射、222 个普通探索入口与 1 个隐藏探索入口检查通过。
- 主页面内联脚本、特性模块语法与差异空白检查通过。

本次浏览器视觉复测因执行环境的自动审批额度不足未能运行。安装包与镜像由 GitHub Actions 构建发布，最终构建结果以对应工作流为准。
