# 地图角标全量矢量替换

正式地图的 504 个普通地图面（含 C5 的 A/B 面）已接入 717 个矢量角标：219 个左下希望／灾祸面板、498 个右下派系面板。C1 的 11 个河流航道与迷宫组合也已包含。7 个 C1 特殊版本沿用原图。

采用已确认的各循环底色、加粗内外框和四角内凹结构；C1 派系保留包边，誓角者使用圆形底，C5 A 面使用浅蓝灰底深色线、B 面使用深蓝灰底浅色线，独眼巨人眼内保留黑色。希望／灾祸沿用之前的矢量图案。23 处边界收紧以避开邻近标记，20 个双希望／灾祸面板按原图顺序排列。

原始 PNG 图层保留不变。新 SVG 内嵌原图，仅遮去审定的角标区域，再叠加矢量路径。C5 顶部编号继续读取原始图层；图标显隐开关同时控制整个标记层。旧资料包没有新 SVG 时先回退到原有高清 PNG 图层。

生成：`python tools/build-map-corner-vectors.py`。核验：`python tools/verify-map-corner-vectors.py`。共享形状和库存位于 `tools/map_corner_vectors.py` 与 `tools/map-corner-vector-source/`。生成的游戏素材留在本地 `map/images/hd1024/overlay/*-corners.svg`。

核验结果：504 个内嵌原图与源文件逐字节一致，717 个面板均为矢量路径，无额外外部图片依赖；27 项地图图层、卡背和角标回归检查通过。已渲染并检查 C1–C5 的整图对照，浏览器端截图未运行。
