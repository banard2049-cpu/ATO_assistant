# ATO Assistant 3.8.2

本次更新删除严重剧透内容，具体内容不做介绍。

## 更新

- 删除严重剧透内容：相关图片、记录表条目与资源包素材一并移除，记录表不再显示该条目。
- 已保存战役中的残留引用在打开记录表时自动清理，其他神之形态、宁芙与战役记录不受影响。
- 同步重打民间版与官方版资源包；旧资源包中的该素材不会在新版程序中显示，建议更新程序后重新导入新版资源包。

## 下载

在本 Release 的 Assets 中选择 Android APK 或 Windows／macOS 便携包。Docker 使用 `ghcr.io/banard2049-cpu/ato_assistant:3.8.2`。

新版资源包仍由本地素材通道分发，不随公开程序安装包上传。程序更新不包含个人存档及游戏图片、故事和音频；已有战役存档与资源包引用继续兼容。

## 验证

- 记录表、航行恢复选项与英文术语表均不再包含被删除条目；旧存档载入后自动清理残留引用。
- Android 导入名单与两版 `.atopack` 打包清单同步移除该素材，资源目录与打包回归测试通过。
- 正式安装包与 Docker 镜像由本标签的 GitHub Actions 构建发布。
