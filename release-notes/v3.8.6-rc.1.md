# ATO Assistant 3.8.6-rc.1

> **请同步更新 ATOPACK。** 本版更新资源和派系图标，并让 AIBP 共用记录表的资源图标。更新程序后，请重新导入最新版 ATOPACK；仅更新程序不会替换本地游戏素材，旧资料包可能继续显示旧图标或缺图。

## 更新

- 科技树外的科技引用统一使用深色面名称，包括交易来源、能力面板、时间线、豁免、提醒、已解锁卡牌列表和简报。例如，“阿尔戈号的任务”在交易中显示为“圆桌舰桥”；科技树仍显示正面名称。
- 旧时间线和科技修复提醒在显示时转换为深色面名称；新操作日志使用相同名称。科技标识、解锁关系及已有手写日志保持兼容。
- 移除资源交换中的“当前正在发展阶段”复选框及对应校验，保留“故事 2A 或之后”的条件确认。
- 更新记录表资源与派系图标，统一图标尺寸，保留白色内部细节；AIBP 战利品面板复用记录表图标。
- 素材库清理已停用的独立 AIBP 资源图和无用标记，避免新 ATOPACK 继续要求或打包这些旧素材。
- 调整部分控件和记录表分隔线外观。

## 下载与升级

这是预发布版本。在本 Release 的 Assets 中选择 Android APK 或 Windows／macOS 便携包；Docker 镜像标签为 `ghcr.io/banard2049-cpu/ato_assistant:3.8.6-rc.1`。

**安装程序更新后，请再次导入最新版 ATOPACK。** 程序包不包含游戏图片、故事和音频资源；已有战役存档继续兼容。预发布不会替换正式版的 `latest` 镜像标签。

## 验证

科技引用、交易结算、简报、资源图标与素材打包相关回归测试及公开发布资源审计通过。Android、便携包和 Docker 镜像由本标签对应的 GitHub Actions 构建发布。
