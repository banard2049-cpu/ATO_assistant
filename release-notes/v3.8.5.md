# ATO Assistant 3.8.5

修正探索卡奖励、连抽与移出规则，完善五循环探索卡打标保存。

## 更新

- 对照全部 223 张探索卡卡面，修正一张卡的同盟奖励类型，以及三张卡的连抽或移出行为。
- 校正六处探索卡英文名称，区分地图派系标记与资源图标。
- 将此前已核实的 27 张卡规则同步回生成输入，避免重新生成时恢复旧转录；完整保留故事书页码与指定派系条件。
- 打标编辑器和保存接口支持全部五循环及隐藏卡；移出与连抽可独立设置。
- 隔离旧版浏览器草稿，局部导入保留其余卡片，防止覆盖新修正或丢失后续循环标签。

本次修正影响更新后的操作与结算，不自动追溯修改历史存档。已有错误奖励回执按提示撤销后重新结算。

## 下载

在本 Release 的 Assets 中选择 Android APK 或 Windows／macOS 便携包。Docker 使用 `ghcr.io/banard2049-cpu/ato_assistant:3.8.5`，正式版同时更新 `latest`。

程序更新不包含个人存档及游戏图片、故事或音频资源；已有战役存档继续兼容。

## 验证

全部 223 张探索卡完成卡面核对；246 项 JavaScript 回归、6 项生成器测试、2 项 PHP 保存标准化测试通过。规则工具自检、脚本语法、生成数据一致性及发布打包检查通过。新增回归已加入持续集成。

正式安装包与 Docker 镜像由本标签的 GitHub Actions 构建发布。Android 尚未进行真机验证。
