## 更新

本版本是 **2.0.0 的第一个预发布（rc.1）**，把「资料包」这条链路重做了一遍：素材真源从素材库换成
ATO_assistant 工程目录，新增民间版 / 官方版两个命令行打包器，并彻底修掉「导出被打断留下一堆打不开的
半成品包」这个老问题。

预发布用于先验证打包与导入链路，**下载页的安装包与 Docker 镜像都是 rc 构建**，正式版会另发。

### 资料包打包：从"素材库导出"改为"工程目录 + 命令行打包器"

- 新增 **`tools/build_fan_pack.py`（民间版）** 与 **`tools/build_official_pack.py`（官方版）**，共用同一份
  打包引擎（写入、校验、原子改名只有一份实现）。两者都以 `--ato-root` 工程目录为素材真源，按固定清单
  （2776 条目 / 4298 个面 / 4279 张图 + 19 首 BGM）出包：

  | | 民间版 | 官方版 |
  | --- | --- | --- |
  | 图片 | 全部取工程目录（4279 张） | `official-assets/` 官中覆盖图优先，缺则保留工程原图（实测替换 1517 张） |
  | 故事书 js | 工程里的民间正文（7 本 / 4552 段） | 用官方数据生成，**只留官方正文**（C1–C3 共 3 本 / 2195 段） |
  | 官方资料 | 只带官方故事书正文数据（1 个文件） | 官方正文数据 + **官方原书扫描图 2195 张**（共 2196 个） |
  | 体积 / 成员 | 2.76 GiB / 4304 | 4.18 GiB / 6499 |

- **为什么换真源**：打包目标路径本来就是工程相对路径，工程目录里那份是平时维护、修正过的。实测素材库
  比工程目录**缺 6 张图**（5 个循环图标 + C1 探索卡 8201）、另有 **59 张是旧版本**——从素材库打包会同时
  出现"发出去的图是旧的"和"少图"两种错。素材库现在只在工程缺图时用 `--library` 兜底。
- 新增 **`tools/check_pack.py`**：检查任意 `.atopack` 是否完整、是什么口径，能一眼认出"没有中央目录的
  半成品"。
- 打包口径对齐仓库里提交的导出程序：官方故事书正文数据默认进包（格式版本 3），官方版原书截图只在显式
  要求时进包。

### 修复：导出被打断不再留下打不开的包

旧导出路径**直接往最终文件写 ZIP**，中途被打断（关掉工具、进程被杀、磁盘写满、下载被掐）留下的就是一个
没有中央目录的半成品——文件头是 `PK\x03\x04`，解压工具只会报"不是 ZIP"，而它顶着 `.atopack` 的名字，
很容易被当成成品发出去。

新打包器的规矩只有一条：**最终文件名上只可能出现完整、已校验的包**。

1. 先写 `<输出>.partial`；
2. 关文件 → 刷盘（`fsync`）；
3. 校验（能打开、成员齐全、大小一致、声明的哈希抽样或全量比对、官方资料与 BGM 齐备）；
4. 通过之后才原子改名成 `.atopack`（Windows 上被杀毒 / 索引器占用时自动重试）。

任何一步失败，最终路径上都不会出现文件，半成品留在 `.partial` 供排查。写盘前还会先卡读取方的上限
（成员数、单成员 128MB、解压总量、图片条目数），避免打出对方整包拒收的包。

## 下载

Windows、macOS、Android 请下载下方对应安装包。便携版请解压到新目录，并保留旧版本的 `data/` 和本地素材
目录（图片、故事数据、`assets/bgm/` 音频都不在安装包里，需要自备）。

Docker 镜像同步发布 `2.0.0-rc.1` 标签。**预发布不会移动 `latest`**，如需固定版本请在 `.env` 里写
`ATO_VERSION=2.0.0-rc.1`，然后运行：

```bash
docker compose pull
docker compose up -d
```

Android 沿用现有签名策略：未配置发布签名密钥时提供 Debug 签名 APK。不同构建的签名可能不一致，无法保证
覆盖升级；卸载会删除应用内账号、存档和素材，升级前请确认数据可恢复。

**安卓导入要求**：APK 需为 **1.4.1 或更新**（内置资源名单 4298 个目标；1.4.0 不认「逆行动量」，更早的版本
不认 C2 探索卡 13642，1.3.2 以前的 APK 不支持格式版本 3）。导入时先把整包拷进应用缓存、再把每个文件落到
内部存储，**需要约 2× 包大小的可用空间**（官方版 4.18 GiB → 约 8.4 GiB；民间版 2.76 GiB → 约 5.5 GiB）。

资料包为本地私有产物，不进仓库、不进安装包；仓库的 `.gitignore` 已排除 `*.atopack`。
