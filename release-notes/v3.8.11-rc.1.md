# ATO Assistant 3.8.11-rc.1

Android 故事书稳定性预发布版：原书扫描图改为点开才加载，混排插图在渲染进程崩溃后自动降级并在页面上提醒。

## 更新

- 官方版故事书的原书扫描图不再随条目自动请求和解码。进入条目只显示「查看原书页」按钮，点开后才加载原图并打开查看器；关闭查看器会清掉图片引用，让解码后的位图可以被回收。
- 扫描图点开失败时仍显示「本地未提供原书页」提示，并同步更新第二屏的图片/文字选项；第二屏的「显示图片」模式不受影响。
- 混排插图始终加载，不再提供关闭开关。如果本次运行中 WebView 渲染进程崩溃过，后续进入故事书会自动跳过十几兆的混排 mapping，并在阅读页顶部显示提醒；完全退出并重新打开 App 后自动恢复。
- 回到主控台后清空 WebView 的前进/后退历史；故事页离开时退出返回缓存，避免第一次的故事页和第二次加载页同时留在渲染进程里。
- 官方正文、人物小传索引仍按需加载，民间版首屏不再解析官方数据。

## 验证

- Android 模拟器同一进程连续进出故事书 5 次，混排 mapping 开启时渲染进程保持稳定；主控台历史长度在返回后清为 1。
- 模拟渲染进程崩溃后，下一次进入故事书自动不加载混排 mapping，并显示降级提醒；完全退出重开 App 后混排恢复。
- 扫描图按钮：进入条目不产生扫描图请求，点开后成功打开原书页，关闭后图片 `src` 被清空；缺失图片的条目正确回退到本地缺失提示。
- 19 项扫描图/第二屏回归测试、Android 102 项 API 检查和 8 个页面加载通过。

## 下载

Windows 选择 `windows-x64.zip`；Apple 芯片 Mac 选择 `macos-arm64.zip`；Intel Mac 选择 `macos-x64.zip`。Android APK 和 Docker 镜像由同一标签的发布流程构建。

这是预发布版本，已有战役存档继续兼容。程序包不含个人存档及游戏图片、故事或音频资源。
