# Boss 等级特性核查

核对范围：等级表中的 21 个 Boss、182 个档位，以及现有独立特性卡与等级大卡。
`boss-trait-rules.js` 为等级表补充卡图映射、明确的取消／替换规则和特性指示物。
等级表继续由 Excel 生成；不会根据条件备注推算额外的固定等级加成。

| Boss | 已补的等级规则 |
| --- | --- |
| 百手巨魔 | II 起移除善意上门；保留零级和一级继承关系 |
| 追踪者 | II 起移除玩弄，撤掉闪避骰−1及每命中危险−1；恢复希望断绝 |
| 尼采 | II 起时不我待禁用留一手，撤掉其危险−1；迁移旧开战指示物 |
| 达哈卡 | I 自动显示恐惧的款待；II 起移除它与悔恨的镣铐；撤掉闪避／危险减值；提醒加入 Trojan Ire／The Oar，III 起提醒翻面 |
| 骇神巨龙 | IV 起以假还真替换以真还真，原卡即使在旧显式选择中也不显示 |
| UR | II 移除只是一段回忆及 AT−1；III 禁用凡性柴薪；VIII 以更深深度替换 Deeper Depths，氧气减量为 2、不叠加此前的 1 |
| 泰坦 X | II 起移除玩弄及减值指示物；万事皆休从 I 即禁用玩弄 |
| 巴别塔 | II 起自动添加现有共享「累累白骨之间」卡；VIII、IX 独立卡保持按等级添加 |

| 半灯神 | 「终极愿望」牌由条件触发，不按 IV 无条件启用；现有愿望流程保留 |
| 黑喙 | 保留专属卡和既有 Toying／Tease 禁用规则 |
| 其余 10 个 Boss | 独立特性按文件等级添加；现有资料没有额外的独立卡取消规则 |

AI 区点击“查看等级特性”，弹窗显示当前生效、移除／禁用及需要手动处理的效果。
大卡内置的玩弄、悔恨的镣铐、留一手也可在 Trait 选择中取消／恢复，立即同步指示物。
被等级取消的卡不可重新勾选；降低等级恢复默认资格，不清除玩家已有的手动隐藏选择。

特性指示物与等级加成、手动指示物分别记录贡献；移除时只减掉该特性的贡献，保留手动
数量、堆 ID 和拖动位置。每命中危险减量与普通危险减量分堆显示，并提醒最低危险为 1。

秘密卡、氧气、地形、状态牌堆与泰坦上的指示物通过文字提示处理，不放到 Boss 面板。
条件卡仍可手动选择查看。第二屏的卡牌快照排除已被等级移除的旧显式选择。
