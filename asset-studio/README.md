# ATO 素材库 WebUI

这是与 ATO_assistant 主站完全独立的本地素材整理工具。工具内置了根据 ATO Local 0.2.11 制作的固定实体素材清单，引导用户逐张拍摄实体卡，支持批量导入、文字故事书解析、资料包分享和安全安装到原项目。用户无需提供 APK。

工具不会把 APK 图片、故事正文或音频写入源码。用户导入的内容只保存在其指定的本机资料库中。

## 启动

- macOS：双击 `start-macos.command`
- Windows：双击 `start-windows.bat`

首次运行会创建 `.venv` 并安装依赖。浏览器自动打开 `http://127.0.0.1:8765`。手机与电脑连接同一 Wi-Fi 后，扫描首页二维码并输入本次配对码。

## 首次使用

1. 选择容量充足的资料库目录，可选设置 ATO_assistant 根目录。
2. 固定清单会自动初始化，无需选择或解析 APK。
3. 手机扫码连接，进入“逐张拍摄”。页面会显示循环、模块、卡名、编号和当前要拍的面。

固定清单包含英雄头像以及英雄记录表使用的 14 个界面图标（技能、三相、
最大/最小似然、潮汐、净化值框和重置图标）。它们在“英雄记录表图标”模块
中单独导入，安装目标为 `hero/assets/`。

通用标记、地图标记、使徒资源、记录表资源和 C4/C5 状态卡均显示中文详细名称，
并保留原文件代号方便核对实体；AT+/AT- 等正负标记会分别列出，不再被合并。
英雄头像、盟友阵营、神形和宁芙也使用中英双语名称，不再只显示图片文件名。

使徒 BP 卡还会显示击破该部位可获得的资源名称与数量；内置映射覆盖 19 个使徒、342 张有资源标注的 BP 或替代 BP 卡。没有直接资源的特殊 BP 会明确标出。

## 安全约定

- 原项目安装只允许电脑本机发起。
- 同名文件默认跳过；勾选替换后才会覆盖，并先保存到资料库的 `backups/`。
- 所有安装路径都必须位于已验证的 ATO_assistant 根目录内。
- 分享前请确认你有权使用和分享相应素材。
