# ATO 素材库 WebUI

ATO 素材库（Asset Studio）是与 ATO_assistant 主站相互独立的本地 Web
工具，用于拍摄、整理、校对、分享并安装实体游戏素材。电脑负责保存资料、解析文档、
导入导出和安装；手机可以通过局域网页面逐张拍照。

工具源码不包含 APK 图片、故事正文或音频。用户导入的内容只保存在自己选择的本地
资料库中，不会上传云端，也不会进入 Git。

## 功能概览

- 内置 ATO Local 0.2.11 及修正版超时神谕 AI 卡的 2595 项固定清单，普通用户无需提供或解析 APK。
- 按循环、模块和子卡组整理素材，并统计完成、缺正面、缺背面、待校对和冲突数量。
- 逐张提示要拍摄的实体名称、编号和当前面；正面完成后继续提示背面和下一项。
- 支持拍照/选择图片、预览、旋转、裁切、重拍、跳过和稍后继续。
- 支持批量导入图片、文件夹和 ZIP，并可自动匹配或按当前清单顺序分配。
- 支持导入带文字层的 PDF、DOCX 和 TXT 故事书，随后拆分、合并和校对段落。
- 支持导入导出 `.atopack`，也可生成符合原项目目录结构的兼容 ZIP。
- 可在电脑端预览安装差异，将素材安全放入 ATO_assistant 对应目录。
- 原图按 SHA-256 去重保存；拍摄图片即时生成 WebP 预览，`.atopack` 恢复的图片则在首次查看时按需生成，避免数千张预览阻塞恢复。大文件采用分块和流式处理。

## 固定清单与名称

清单根据指定版本预先整理在源码中，不会要求普通用户选择 APK。它覆盖探索卡、
故事/灾厄卡、地图板块、19 个使徒的 AIBP、装备、科技、英雄/盟友、通用标记、
资源图标、状态卡和故事书结构。清单也包含使徒完整面板、故事书配图、C5 故事书
补充页、科技树总览、泰坦职业配图，以及 C5 地图的水上/潜水状态图标。

容易混淆的素材均显示具体名称，同时保留文件代号便于核对实体：

- 17 个 AIBP 标记，包括分别列出的 AT+/AT-、DA+/DA-、闪避、命中、精准和速度标记。
- 19 个地图标记，包括阿尔戈号、使徒、侦察船、最后到访地点和后日奥德赛补给。
- 26 个使徒资源图标和 66 个记录表资源图标，例如黑色锁链、神浆原液和军备。
- 13 张 C4/C5 状态卡，显示中英文卡名和固定编号。
- 26 个英雄头像、15 个盟友阵营以及 39 项神形/宁芙素材，显示中英双语名称。
- 14 个英雄记录表界面图标，包括技能、三相、最大/最小似然、潮汐、净化值框和重置图标。

使徒 BP 或替代 BP 卡会在拍摄页显示可获得资源的名称和数量。映射覆盖 19 个使徒、
342 张有资源标注的卡；没有直接资源的特殊 BP 也会明确提示。

## 启动

需要 Python 3.11 或更高版本。首次启动需要联网安装 Python 依赖，之后可以离线使用。

- macOS：双击 `start-macos.command`
- Windows：双击 `start-windows.bat`

启动脚本会创建 `.venv`、安装依赖、在 `http://127.0.0.1:8765` 启动服务并打开浏览器。

## 首次设置与手机拍摄

1. 选择空间充足的资料库目录。
2. 如已确定原项目位置，可同时填写 ATO_assistant 根目录；也可以稍后设置。
3. 固定清单会自动初始化，不需要 APK。
4. 电脑首页会显示局域网地址、二维码和本次临时配对码。
5. 手机与电脑连接同一个 Wi-Fi，扫描二维码并输入配对码。
6. 进入“逐张拍摄”，可按循环和模块筛选；页面会明确提示下一张实体及正反面。

未经配对的局域网设备不能查看或上传素材。关闭并重新启动工具后会生成新的临时配对码。

## 批量导入

在“批量导入”中可以选择多张图片、整个文件夹或 ZIP：

- 工具优先按目标路径、文件名和卡号自动匹配。
- 无法确定或存在多个候选的图片会进入“待分配图片”队列。
- 已按清单顺序拍摄的一组连续照片，可以点击“按当前清单顺序分配”。
- `.atopack` 不在此处导入，应在“分享与安装”中选择。

## 故事书导入

“故事书”页面支持 PDF、DOCX 和 TXT。填写故事书 ID、标题、章节以及可选页码范围后，
点击“解析并进入校对”。导入后可修改编号和正文，并对段落进行拆分、合并和校对。

PDF 必须带有可提取的文字层。扫描图片型 PDF 不支持 OCR；检测不到文字时工具会报错，
不会生成空白故事。分享包只包含校对后的结构化段落，不包含原 PDF 或 DOCX。

## 把拍摄图片安装到 ATO_assistant

安装操作只能从电脑本机发起。完成拍摄或导入后：

1. 打开顶部的“分享与安装”。
2. 在“原项目位置”填写 ATO_assistant 根目录。正确目录应包含 `index.html`、`map/`、
   `story/` 等内容，然后点击“保存路径”。
3. 点击“预览自动安装”。工具会列出新增、相同和冲突文件。
4. 新文件默认安装；同名文件默认保留原项目版本。只有需要覆盖时才勾选对应替换项。
5. 点击安装差异面板右上角的“安装新增与已选替换”。

替换前会把旧文件保存到资料库的 `backups/`。安装路径必须位于所选 ATO_assistant
根目录内；工具不会删除原项目文件，也不会修改其业务源码。如果不想直接写入原项目，
可以点击“生成兼容 ZIP”后自行解压检查。

## 与朋友分享

`.atopack` 包含所选卡图、清单映射、完成状态、文件哈希和校对后的结构化故事。
导出时可按循环、模块和完成状态筛选。朋友在“分享与安装”中选择该文件后，工具会先
校验并预览新增、相同和冲突内容，再由用户决定保留现有素材还是替换冲突。

资料包可能达到数 GB，生成和导入需要等待一段时间。仓库的 `.gitignore` 已排除
`*.atopack`，因此本地生成的资源包不会被意外提交到 GitHub。

## 数据与安全

- 原图、预览图、SQLite 资料库、导出包和备份都位于用户选择的资料库目录。
- 同名文件默认跳过；只有明确勾选后才会替换。
- 安装失败时会保留备份并执行回滚。
- 工具不会从用户 APK 动态生成清单，也不会把 APK 内容写入源码。
- 分享素材前，请确认自己有权使用和分享相应图片与故事内容。

## 开发验证

在 `asset-studio/` 目录运行：

```bash
.venv/bin/python -m unittest discover -s tests -v
```

macOS/Linux 也可以手动运行服务：

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m app.main
```
