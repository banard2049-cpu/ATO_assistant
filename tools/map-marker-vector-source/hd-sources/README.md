# 高清原版图案来源与重绘要求

本轮替代上一轮被否决的简化试稿。参考必须与地图中的原版图案同形，不能仅凭类别名称拿相似符号代替。

- `token-originals/` 保存用户指定 Mods 中的原始图片副本和未经重采样的参考裁剪。每项包含原路径、TTS 对象引用、图片尺寸和 SHA-256。
- token 的图案必须与地图逐项视觉核对；候选细塔不等于条纹杖，浮空城堡不等于地图的斯巴达要塞，带海浪灯塔也不能直接替换不同形状的地图灯塔。
- 高清参考仅用于确认轮廓、比例、留白和内部细节。正式替换通过同一套固定元素组合；同一图案只制作一份组件，颜色和底座为独立参数。
- 已发现绿洲中央实际为圆顶建筑，上一轮的动物状简化属于误读，不能沿用。

参考图数量、下载成功或 SVG 结构检查不能证明“几乎一模一样”。正式使用前应同时检查放大原图对照、实际显示尺寸、结构细节及轮廓差异。
