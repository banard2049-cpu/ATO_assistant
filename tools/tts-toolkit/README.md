# ATO 故事书语音工具包

一个本地网页工具：**选数据文件 → 填讯飞账号和音色 → 点按钮批量生成**离线朗读音频。

生成的核心逻辑复用 `tools/generate-story-xfyun-tts.mjs`，工具包只是给它套了一个界面。

## 启动

| 系统 | 双击 |
| --- | --- |
| Windows | `start-windows.bat` |
| macOS | `start-macos.command` |

也可以手动启动：

```powershell
node tools/tts-toolkit/server.mjs
```

服务只监听 `127.0.0.1`（默认端口 8791，被占用会自动往后试），浏览器会自动打开。
**关闭那个命令行窗口就停止服务。**

需要 Node.js 18 或更高版本。

## 使用步骤

1. **数据来源**：从下拉框选 `story/data/storybook-official-data.js`（官方版正文）。
   想读别的数据文件，直接手动填相对路径即可。
2. **讯飞账号**：填 AppID / APIKey / APISecret，点「保存账号」。
   密钥只写进本机 `tools/xfyun-long-tts.config.json`，**不会上传、也不会回传浏览器**；
   界面上只显示掩码（如 `3f90••••4b7c`）。留空表示沿用已保存的值。
3. **音色与参数**：选或填 vcn（默认 `x4_lingbosong_bad_talk` 聆伯松-反派老人），调语速/音量/音调。
4. 建议先点「测试连接」——它会真的合成一小段（消耗 1 次额度），能立刻分出是
   「服务没开通」还是「这个发音人没授权」。
5. 点「预览计划」确认条目数，再点「开始批量生成」。

## 四个按钮

| 按钮 | 作用 | 消耗额度 |
| --- | --- | --- |
| 测试连接 | 合成一小段验证账号、服务、音色是否可用 | 1 次 |
| 预览计划 | 只统计将要生成多少条，不合成 | 否 |
| 开始批量生成 | 正式批量生成，可随时停止 | 是 |
| 重建播放清单 | 扫描已有音频重建 `manifest.json` / `manifest.js` | 否 |

## 会自动跳过已生成的

目标音频文件已存在时直接复用，不重复调用接口。所以**中断后直接再点一次「开始批量生成」即可续跑**。

「强制重新生成」勾上才会覆盖已有文件（会重新消耗额度）。

## 额度提醒

在线语音合成**每个分片算 1 次调用**，新应用默认**每日 500 次**，超出会报 `11201`。
全库（排除战斗模块）约 2178 条。用「高级选项」里的「只生成前 N 条」或分书（c1 / c2 / c3）分批跑，
第二天再点一次即可接着生成。

## 战斗模块

官方数据里的条目本身不带章节信息，工具会读 `story/data/storybook-data.js` 按条目 key 反查，
和网页端 App 用的是同一套规则。`chapterKey === "battle"` 即战斗模块，**默认跳过**（共 17 条）。
需要生成就勾上「包含战斗模块」。

## 中断后清单对不上？

生成时清单是在整批跑完才写入的，所以中途「停止」或关窗口后，
最后几条音频可能已落盘但不在清单里，网页端读不到。

点一次「重建播放清单」即可修复——它只扫磁盘，不调用接口。

## 文件说明

```
tools/tts-toolkit/
  server.mjs            本地服务（只监听 127.0.0.1）
  start-windows.bat     Windows 启动器
  start-macos.command   macOS 启动器
  public/
    index.html          界面
    app.js              界面逻辑
    styles.css          样式
```

输出目录默认 `story/audio-packs/audio-lingbosong/`，生成后在故事页把朗读引擎选为
「离线保存音频」，音色选「聆伯松-反派老人（官方版）」。

## 环境变量

| 变量 | 说明 |
| --- | --- |
| `ATO_TTS_PORT` | 起始端口，默认 8791 |
| `ATO_TTS_NO_OPEN` | 设为任意值则不自动开浏览器 |
