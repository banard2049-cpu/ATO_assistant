ATO Assistant Portable

1. Extract the whole ZIP to a writable folder.
2. Windows: double-click start-ato-portable.bat.
   macOS: double-click start-ato-portable.command.
3. The browser opens http://127.0.0.1:8793/ automatically.

PHP and its required runtime libraries are included. No system PHP, Docker, Node.js,
Python, or tools directory is required. Saves stay in the data folder next to
the launcher, so moving that folder moves the application and its saves.
