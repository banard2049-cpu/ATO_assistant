# ATO 手机端交互预览

八个页面全部复用项目现有 HTML、素材和交互脚本。只调整手机布局、工具面板与定位入口，不维护另一个删减版界面，不改页面名称、按钮原文、游戏术语或同功能图标。预览不会写入正式页面或正式存档。正式 APK 的竖屏布局单独位于 `assets/mobile/`，不加载本目录的内存服务。

## 打开预览

在项目根目录运行现有路由器：

```powershell
php -S 0.0.0.0:8793 -t . router.php
```

- 统一入口：`http://127.0.0.1:8793/tools/mobile-preview/`
- 截图入口：`http://127.0.0.1:8793/tools/mobile-preview/gallery.html`
- 手机：使用电脑的局域网地址打开统一入口，自动铺满可用屏幕。
- 直接进入模块：`screen.html?page=dashboard`，还支持 `record`、`hero`、`aibp`、`technology`、`map`、`story`、`briefing`。

桌面可以选择 360×780、390×844、430×932、844×390 或旋转尺寸。顶部 48px 单独模拟 Android 页面标签，可切换、关闭和重新打开。页面标题与常驻导航最多两行；工具面板最多占页面可用高度的 85%，支持关闭、遮罩、返回和恢复阅读位置。

## 完整功能与示例状态

`source-host.js` 载入八个正式页面及它们的全部原脚本。`dashboard-layout.js` 和三个 `source-*.js` 布局适配器移动现有 DOM 节点，保留原 ID、原事件和原功能。

- 主控台保留七步流程、探索抽牌与结算、考察定数、科技能力、剧情定数、故事与灾祸进度、日期轨、战役日志、用户与存档及全部设置。
- 阿尔戈号记录表保留全部分区、轨道、矩阵、图片附件及就地编辑；矩阵局部横滑，工具面板提供按原分区名称定位的入口。
- 英雄记录表保留技能、回忆、宿命回忆、排序、重置、添加和墓园，增加一行按原英雄名称定位的入口。
- 始徒保留完整列表、AI/BP、Trait、Token、晋升、观星、战斗地图及全部原设置。
- 科技保留五个循环、已解锁科技、装备制造、军械库、资源操作、原筛选与卡牌详情。树图首次定位到可读节点，仍可使用原总览、缩放和定位按钮；节点坐标不变。
- 地图保留全部板块、图层、标记、侦察船、仇敌、标签、笔记和管理操作；原循环按钮与原缩放输入留在画布旁，另有定位阿尔戈号入口。示例默认缩放为 300%，坐标不变。
- 故事书使用原完整书目与正文，保留目录、搜索、书签、密语、人物资料、朗读及原引擎配置。
- 战役简报保留每日回放、所有中枢与轨道、地图与科技回放、统计、原 GIF/PDF 导出和备份迁移。

`source-runtime.js` 在应用代码执行前替换浏览器存储和网络传输。localStorage、sessionStorage、IndexedDB、跨页广播及所有业务 API 使用独立内存；八页共享同一份示例战役，跨页修改与自动日志可见。内部跳转、深链接、保存返回和重载都经过预览加载器。CSP 禁止子页面直接连接业务服务，父页面只读取公开源码和素材；不读取真实账号、存档、图片附件或备份。

`source-store.js` 提供内存存档与附件服务；`source-backups.js` 提供内存每日备份 ZIP 的导出、校验、导入和重复识别。文件操作沿用原控件，对象仅为预览数据。刷新统一入口或点击“重置示例”清空本次状态。预览不会改写原始业务页面。

与环境有关的功能沿用原界面：第二屏设置只保存示例配置，不启动第二屏服务；安装与回滚不执行；原生 Android 桥接不加载。浏览器朗读可直接使用，用户自行填写的外部朗读服务通过预览代理连接，不继承正式页面的凭据。

## 检查与截图

服务器运行时执行：

```powershell
node tools/mobile-preview/verify-full-source.cjs
```

脚本使用本机 Chrome 和原生 DevTools 协议，无 npm 依赖。可通过 `CHROME_PATH` 指定浏览器，通过 `ATO_PREVIEW_URL` 指定以 `/tools/mobile-preview/` 结尾的地址。设置 `ATO_PREVIEW_QUICK=1` 仅检查 390×844，供修改时快速验证。

检查覆盖四种尺寸的八页默认首屏与工具面板，核对全部原静态控件 ID 和全部原外部脚本。交互检查包括主控台七步流程与探索抽牌、故事卡详情、原资源编辑与自动日志及分区定位、英雄技能与回忆、始徒抽牌与结算、Token、地图操作与保存返回、科技详情与多项筛选、军械库补录、故事跳转与书签、密语与朗读配置、简报空记录、BGM 导入、ZIP 备份、GIF/PDF 的画布读取及重载。另用缩小的可用视口模拟输入键盘占用，检查工具滚动和关闭后的阅读位置；这不代替实体 Android 输入法测试。

报告：`output/mobile-full-source-verification.json`。局域网 HTTP 入口另有 `output/mobile-preview-lan-verification.json`；其中备份与附件的 SHA-256 沿用故事书已有的纯 JavaScript 回退实现，不依赖 HTTPS。16 张截图位于本目录 `screenshots/`，由 `gallery.html` 展示；截图按现有项目规则仅保留本地。预览需要支持 Navigation API 的现代 Chromium 浏览器，以保留原程序跳转行为并限制在预览内。

此目录属于开发工具，遵循项目已有打包排除规则，不进入 APK 或便携版。
